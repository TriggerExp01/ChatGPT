# Phase77A UI 字体说明

本目录用于 Phase77A Cultivation UI 黄金样板。

- `NotoSansCJKsc-VF.ttf`：用于中文 TextMeshPro 样板字体。
- `NotoSansCJKsc_Phase77A SDF.asset`：由 Unity Editor 生成器从上述字体创建的 TMP 字体资产。
- `NotoCJK_LICENSE_OFL.txt`：Noto CJK Sans 的 OFL 授权文件，来源为 `notofonts/noto-cjk` 仓库 `Sans/LICENSE`。
- `NotoCJK_README_source.md`：来源仓库 README 快照。

本阶段字体用于原型视觉基线，不代表最终产品字体已经锁定。正式产品化前应再次确认字体授权、体积、平台兼容性和是否需要子集化。
