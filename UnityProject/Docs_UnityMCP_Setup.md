# Unity MCP Setup

This project uses MCP for Unity:

```text
https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main
```

The package is declared in `Packages/manifest.json` as:

```json
"com.coplaydev.unity-mcp": "https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main"
```

## Prerequisites

- Unity 2022.3.17f1 for this project.
- Python 3.10+.
- `uv`.
- An MCP-capable client.

This machine currently has:

```text
Python 3.10.11
uv 0.10.9
Node.js v24.14.0
npm 11.9.0
```

## Enable In Unity

1. Open `UnityProject` in Unity.
2. Let Unity Package Manager resolve the new package.
3. Open `Window > MCP for Unity`.
4. Complete the first-run setup if prompted.
5. Click `Start Server`.
6. Confirm the status shows connected/ready.

Default HTTP endpoint:

```text
http://localhost:8080/mcp
```

## Client Configuration

For MCP clients that support HTTP servers:

```json
{
  "mcpServers": {
    "unityMCP": {
      "url": "http://localhost:8080/mcp"
    }
  }
}
```

For stdio clients, use the snippet generated by `Window > MCP for Unity`, because the exact `uvx` path can vary per machine.

## Expected Tools

The package should expose tools such as:

- `manage_scene`
- `manage_gameobject`
- `manage_components`
- `manage_ui`
- `manage_prefabs`
- `manage_camera`
- `read_console`
- `manage_editor`
- `batch_execute`

These are the tools needed to build and verify uGUI prefabs directly in the Unity Editor.
