# 视觉资产来源与许可清单

## 目的

本清单用于记录当前肉鸽玩法相关视觉资产的来源、作者、许可和用途。后续替换为外部免费资源时，必须先补充本清单，再进入 Unity 验证与提交。

## 使用规则

1. 仅允许使用自制、AI 生成并可商用、CC0、公有领域、OFL 字体或明确允许商用的免费资源。
2. CC-BY 或其他需要署名的资源必须记录作者、来源链接、许可链接和署名文本。
3. 禁止商用、仅限个人使用、来源不明或许可不清的资源不得进入 `UnityProject/Assets/AssetRaw`。
4. 外部资源进入工程后，应优先落在 `Assets/AssetRaw` 下的既有资源链路，并继续使用 TEngine/YooAsset 资源模块。
