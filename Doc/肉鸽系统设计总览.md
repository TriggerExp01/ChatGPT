# 肉鸽系统设计总览

## 当前产品方向

- 类型：类《吸血鬼幸存者》的俯视角 2D 自动战斗肉鸽。
- 核心体验：玩家移动、武器自动攻击、持续刷怪、经验升级、随机强化和构筑成长。
- 当前策略：按阶段完成并运行验收，不跨阶段堆功能。
- 当前路线：[类吸血鬼幸存者阶段开发路线.md](D:/Work/Unity_Project/TEngine_Game/Doc/类吸血鬼幸存者阶段开发路线.md:1)

## 当前系统职责

- 单局流程：开始、游玩、升级暂停、死亡、结算、重开。
- 玩家：移动、生命、属性和受伤。
- 敌人：生成、追踪、攻击、受伤和死亡。
- 武器：自动搜敌、攻击、伤害和后续多武器成长。
- 成长：经验、等级、升级三选一和后续被动道具。
- 关卡：时间、刷怪节奏、难度成长和后续地图扩展。
- UI：生命、经验、等级、时间、击杀、升级和结算。

## 工程原则

1. 优先复用 TEngine 和项目已有方案。
2. 代码简洁、高效，不为未确认需求过度设计。
3. 每次只推进一个阶段，通过 Unity 运行验收后再进入下一阶段。
4. 原型阶段优先保证核心闭环，配置化、对象池和内容扩展后置。
5. 用户可见文案和项目文档使用中文。

## 当前主要风险

1. 阶段 9 对象池与性能优化尚未开始，需要先检查并复用 TEngine 或项目已有对象池能力。
2. 当前生存原型数值仍主要硬编码，Luban 配置化按阶段 13 后置。
3. 当前部分生存玩法逻辑集中在 `RoguelikeGame`，仅在实际阻碍下一阶段时做最小拆分。
