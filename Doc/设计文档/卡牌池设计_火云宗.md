# 火云宗 · 完整卡牌池设计

> **项目适配说明**：本文档由 `C:/Users/hirusumi/Downloads/仙途天命_完整设计文档.md` 拆分并适配到当前 Unity + TEngine 项目。实现以 `D:/Work/Unity_Project/TEngine_Game` 仓库为准；设计文档统一存放在 `Doc/设计文档`。
> **拆分日期**：2026-06-20


> **门派定位**：灼烧DOT + 爆发AOE + 烈焰印记引爆
> **设计哲学**：火云宗与剑宗形成鲜明对比——剑宗追求"当前回合击杀"，火云宗享受"看着敌人被烧死"。火云宗的策略深度在于"伤害的时间分布管理"。
> **核心机制关键词**：灼烧、烈焰印记、引爆、AOE、灰烬
> **卡牌总数**：35张（门派专属27张 + 通用丹药/法宝8张见通用池）

---

## 机制关键词说明

| 关键词 | 触发/效果 | 设计意图 |
|--------|----------|----------|
| **灼烧** | 每回合开始造成N点伤害，持续M回合 | 核心DOT——总伤害高但延迟兑现 |
| **烈焰印记** | 叠至4层时引爆，造成20点伤害 | 比剑气印记更高门槛更高回报的叠层机制 |
| **引爆** | 立即结算目标身上所有灼烧伤害（并移除灼烧） | 灼烧体系的爆发手段——"不想等就现在结算" |
| **AOE** | 对全体敌人造成伤害 | 火云宗特色——烈火燎原 |
| **灰烬** | 敌人死亡时对全体敌人施加1层灼烧 | 连锁反应——击杀产生AOE灼烧 |

## 一、攻击功法 (14张)

### 凡品 (5张)

---

#### 1. 烈火掌
```
稀有度: 凡品 | 灵力: 1 | 类型: 攻击功法·掌
效果: 造成 6 伤害 + 施加1层灼烧(3回合)
设计意图: 基准火系牌——比剑气诀少2直伤但多3回合灼烧(总价值9)。教玩家理解"延迟伤害"的价值。
       总期望伤害=6+3×3=15，远高于1灵力基准8，但分布在4回合中。
五行: 火
```

**升级树**：
```
烈火掌 (1灵/6伤/灼烧1层3回合)
├─ 1A: 烈焰掌 → 伤害+3 (9伤/灼烧1层)
│  ├─ 2A: 焚天掌 → 灼烧层数+1 (9伤/灼烧2层)
│  └─ 2B: 爆裂掌 → 灼烧变为2层但持续2回合(总伤不变但更快)
│
└─ 1B: 火毒掌 → 灼烧持续+1回合 (6伤/灼烧1层4回合)
   ├─ 2C: 火煞掌 → 灼烧伤害+1/回合 (6伤/灼烧1层4回合每层2伤)
   └─ 2D: 烈火绵掌 → 灵力消耗-1 (0灵/6伤/灼烧1层3回合)
```

## 七、火云宗 vs 剑宗 设计对比

| 维度 | 剑宗 | 火云宗 |
|------|------|--------|
| **核心伤害类型** | 直接物理伤害 | DOT灼烧+引爆 |
| **伤害兑现速度** | 立即 | 延迟但有爆发手段 |
| **对单能力** | 极强（破防+破军斩combo） | 强（灼烧堆积+炎爆） |
| **对多能力** | 中（横扫、万剑归宗） | 极强（AOE灼烧、连锁引爆） |
| **防御风格** | 护盾+印记积累 | 护盾+灼烧反伤 |
| **核心资源** | 剑气印记(3层引爆) | 灼烧层数+烈焰印记(4层引爆) |
| **新手友好度** | 高（直觉型直伤） | 中（需理解延迟伤害价值） |
| **高手上限** | 高（连击combo链） | 极高（灼烧时机管理+引爆timing） |
| **标志性感受** | "一剑破万法" | "看着他们烧成灰烬" |
