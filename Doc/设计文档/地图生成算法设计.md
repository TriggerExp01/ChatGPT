## 一、地图总体结构

### 1.1 每层境界地图

```
炼气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 → 渡劫
  15节点    16节点    17节点    17节点    16节点   Boss
```

每层境界的地图是**独立生成**的，击败Boss后进入下一层时重新生成。

### 1.2 单层地图结构

```
行15 ──────────── [Boss] ────────────     ← Boss行(固定1个节点)
行14 ───── / ───── \ ───── / ────────     ← Boss前休息行
行13 ─ / ─ \ ─── / ─ \ ─── / ─── \ ──     ← 普通行
 ...           (中间12行)            ──
行02 ─ / ─ \ ─── / ─ \ ─── / ─── \ ──     ← 普通行
行01 ──── [起点] ────────────────────     ← 起点行(固定1个节点)

列:  1    2    3    4    5    6    7
```

**结构规则**：
- **起点**：固定1个节点，位置在底行中央
- **Boss**：固定1个节点，位置在顶行中央
- **中间行**：每行1-3个节点，节点间有路径连接
- **路径**：只能向上/斜上方移动，不能回头
- **总行数**：15行（炼气期），含起点和Boss

## 二、路径生成算法

### 2.1 路径生成规则

采用**自顶向下**的路径生成——先保证起点到Boss有路，再填充中间节点。

```csharp
// 伪代码 - 路径生成
public class MapGenerator
{
    public MapState Generate(int seed, int realmLevel)
    {
        var rng = new System.Random(seed);
        int rows = 15 + Math.Min(realmLevel, 2); // 境界越高行数略增
        int cols = 7;

        var map = new MapState(rows, cols);

        // 1. 生成3-4条主路径(从起点到Boss)
        int pathCount = 3 + rng.Next(0, 2); // 3或4条
        for (int i = 0; i < pathCount; i++)
        {
            GenerateMainPath(map, rng, rows, cols);
        }

        // 2. 填充剩余空位为可选节点
        FillRemainingNodes(map, rng, realmLevel);

        // 3. 分配节点类型
        AssignNodeTypes(map, rng, realmLevel);

        // 4. 放置Boss
        map.SetNode(rows - 1, cols / 2, NodeType.Boss);

        return map;
    }

    void GenerateMainPath(MapState map, Random rng, int rows, int cols)
    {
        int currentCol = cols / 2; // 从中央起点出发
        map.SetNode(0, currentCol, NodeType.Start);

        for (int row = 1; row < rows - 1; row++)
        {
            // 移动方向: -1(左上), 0(正上), +1(右上)
            int direction = rng.Next(-1, 2);
            currentCol = Mathf.Clamp(currentCol + direction, 0, cols - 1);

            if (!map.HasNode(row, currentCol))
                map.SetNode(row, currentCol, NodeType.Unassigned);

            // 连接路径
            map.ConnectPath(row - 1, prevCol, row, currentCol);
        }

        // 连接到Boss
        map.ConnectPath(rows - 2, currentCol, rows - 1, cols / 2);
    }
}
```

### 2.2 路径约束

| 规则 | 说明 | 设计意图 |
|------|------|----------|
| **不能回头** | 路径只能向上/斜上 | 玩家始终在前进 |
| **不能跨列** | 每步最多移动1列 | 避免出现"跳跃"路径 |
| **起点固定** | 底行中央 | 统一Run起点 |
| **Boss固定** | 顶行中央 | 统一Run终点 |
| **主路径保证** | 至少3条不重叠的主路径 | 确保有选择空间 |
| **行节点上限** | 每行最多3个节点 | 避免信息过载 |

### 2.3 路径连通性验证

生成后必须验证：
- [ ] 从起点到Boss至少有3条不同路径
- [ ] 每个节点至少有1条入边和1条出边（除起点和Boss）
- [ ] 不存在"死胡同"（能进不能出的节点）
- [ ] 不存在"孤岛"（无法到达的节点）

如果验证失败，重新生成。

## 三、节点类型分配

### 3.1 节点类型权重

| 节点类型 | 符号 | 炼气期权重 | 筑基期+ | 设计意图 |
|----------|------|-----------|---------|----------|
| 普通战斗 | ⚔️ | 50% | 45% | 主要内容来源 |
| 精英战斗 | 💀 | 8% | 12% | 高风险高回报，随境界增加 |
| 坊市 | 🏪 | 10% | 10% | 经济节点 |
| 闭关 | 🧘 | 12% | 10% | 恢复+升级 |
| 秘境 | 🌀 | 15% | 18% | 随机事件，随境界增加 |
| 宝箱 | 🎁 | 5% | 5% | 纯奖励节点 |

### 3.2 分配规则

```csharp
void AssignNodeTypes(MapState map, Random rng, int realmLevel)
{
    var nodes = map.GetAllUnassignedNodes();

    foreach (var node in nodes)
    {
        // 起点行和Boss行不分配(已固定)
        if (node.row == 0 || node.row == map.Rows - 1) continue;

        // Boss前一行必须是闭关(给玩家最后准备机会)
        if (node.row == map.Rows - 2)
        {
            node.type = NodeType.Meditation;
            continue;
        }

        // 第2行(起点后第一行)必须是普通战斗(教学)
        if (node.row == 1 && realmLevel == 0)
        {
            node.type = NodeType.Combat;
            continue;
        }

        // 按权重随机分配
        node.type = RollNodeType(rng, realmLevel);
    }
}

NodeType RollNodeType(Random rng, int realmLevel)
{
    float roll = (float)rng.NextDouble();
    float combatWeight = realmLevel == 0 ? 0.50f : 0.45f;
    float eliteWeight = realmLevel == 0 ? 0.08f : 0.12f;
    float shopWeight = 0.10f;
    float medWeight = realmLevel == 0 ? 0.12f : 0.10f;
    float eventWeight = realmLevel == 0 ? 0.15f : 0.18f;
    float chestWeight = 0.05f;

    if (roll < combatWeight) return NodeType.Combat;
    roll -= combatWeight;
    if (roll < eliteWeight) return NodeType.Elite;
    roll -= eliteWeight;
    if (roll < shopWeight) return NodeType.Shop;
    roll -= shopWeight;
    if (roll < medWeight) return NodeType.Meditation;
    roll -= medWeight;
    if (roll < eventWeight) return NodeType.Event;
    return NodeType.Chest;
}
```

### 3.3 特殊约束

| 约束 | 规则 | 原因 |
|------|------|------|
| **无连续精英** | 同一路径上不能有2个相邻精英 | 精英战消耗大，连续打不公平 |
| **坊市间距** | 任意2个坊市之间至少隔3个节点 | 避免坊市扎堆 |
| **闭关间距** | 任意2个闭关之间至少隔2个节点 | 避免恢复过多 |
| **宝箱稀缺** | 每层最多2个宝箱 | 宝箱是纯奖励，不能太多 |
| **首行保护** | 第1-2行不出现精英/秘境 | 前期不能太难 |
| **Boss前闭关** | Boss前一行必定是闭关 | 给玩家最后准备机会 |

## 四、地图可视化规则

### 4.1 玩家可见信息

```
玩家在地图上能看到:
  ✅ 所有节点的位置
  ✅ 所有节点的类型(图标)
  ✅ 所有路径的走向
  ✅ 当前位置(高亮)
  ✅ 可前往的节点(闪烁)

玩家看不到的:
  ❌ 战斗的具体敌人(进入才知道)
  ❌ 秘境的具体事件(进入才知道)
  ❌ 坊市的具体商品(进入才知道)
  ❌ 宝箱的具体法宝(打开才知道)
```

### 4.2 节点预览

悬停节点时显示：
- **战斗**：显示"战斗"（不显示敌人类型）
- **精英**：显示"精英战斗"（不显示具体精英）
- **坊市**：显示"坊市"（不显示商品）
- **闭关**：显示"闭关修炼"（显示"恢复30%HP 或 升级1张卡"）
- **秘境**：显示"秘境探索"（不显示具体事件）
- **宝箱**：显示"宝箱"（不显示内容）
- **Boss**：显示Boss名称 + 天劫类型

## 五、种子系统

### 5.1 种子设计

```csharp
// 种子格式: RealmLevel-SectId-PlayerSeed
// 例如: 0-sword-1234567890

public class MapSeed
{
    public int realmLevel;   // 境界层(0-4)
    public string sectId;    // 门派ID
    public int playerSeed;   // 玩家种子(每次Run随机生成)

    public int GetMapSeed()
    {
        // 组合为确定性种子
        return realmLevel * 1000000 + sectId.GetHashCode() + playerSeed;
    }
}
```

### 5.2 可复现性

- **相同种子 = 相同地图**：玩家可以分享种子，其他人能体验完全相同的Run
- **每日修行**：固定种子，全球相同
- **种子显示**：Run结算界面显示本次种子，方便分享

## 七、地图UI交互规范

### 7.1 地图操作

| 操作 | 行为 |
|------|------|
| **悬停节点** | 显示节点类型tooltip |
| **点击可达节点** | 确认前往 → 过渡动画 → 进入节点内容 |
| **点击不可达节点** | 无反应(灰色节点) |
| **缩放** | 鼠标滚轮缩放地图(适应大屏/小屏) |
| **拖拽** | 鼠标右键拖拽平移地图 |

### 7.2 过渡动画

```
点击可达节点 → 节点放大0.2s → 屏幕渐暗0.3s → 加载节点内容 → 屏幕渐亮0.3s
总过渡时间: 约0.8s
```
