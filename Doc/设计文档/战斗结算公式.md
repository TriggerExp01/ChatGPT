## 一、伤害结算链（核心）

当一张攻击功法造成伤害时，按以下顺序逐步结算：

```
步骤1: 基础伤害
  → 步骤2: 力量/攻击力加成
    → 步骤3: 暴击判定
      → 步骤4: 伤害倍率（如不动明王斩的×3）
        → 步骤5: 目标防御力减免
          → 步骤6: 目标护盾吸收
            → 步骤7: 最终HP扣减
```

### 1.1 每步详细公式

```csharp
/// <summary>
/// 完整伤害结算链 — 所有伤害必须经过此函数
/// </summary>
public int ResolveDamage(DamageContext ctx)
{
    int damage = ctx.BaseDamage;

    // ── 步骤1: 基础伤害 ──
    // 已经是卡牌面板数值，无需处理
    // 例: 剑气诀 BaseDamage = 8

    // ── 步骤2: 力量/攻击力加成 ──
    // POWER修饰器: FLAT_ADD 先算，PCT_ADD 后算
    int flatPower = ctx.Attacker.GetModifierSum(StatType.POWER, Operation.FLAT_ADD);
    int pctPower = ctx.Attacker.GetModifierSum(StatType.POWER, Operation.PCT_ADD);
    damage = (damage + flatPower) * (100 + pctPower) / 100;
    // 例: 8基础 + 5力量 = 13, 再×1.25(强化) = 16

    // ── 步骤3: 暴击判定 ──
    // 暴击率: 基础10% + 修饰器加成 + 法宝加成
    // 暴击伤害: 基础150% + 修饰器加成
    int critRate = ctx.Attacker.CritRate; // 基础10 + 暴击强化等
    int critMultiplier = ctx.Attacker.CritMultiplier; // 基础150
    if (rng.Next(0, 100) < critRate)
    {
        damage = damage * critMultiplier / 100;
        ctx.IsCrit = true;
    }
    // 例: 16 × 150/100 = 24 (暴击)

    // ── 步骤4: 伤害倍率 ──
    // 如: 不动明王斩(×3)、天魔解体(×2)、人剑合一(+3固定)
    damage = damage * ctx.DamageMultiplier / 100;
    // 例: 24 × 300/100 = 72 (不动明王斩暴击)

    // ── 步骤5: 目标防御力减免 ──
    // 防御力 = 基础防御 + 岩甲层数 + 防御修饰器
    // 锋锐: 无视N点防御
    // 破防: 防御力×50%(1层) 或 ×25%(2层)
    int targetDefense = ctx.Target.GetCurrentDefense();
    int effectiveDefense = targetDefense - ctx.AttackerArmorPen; // 锋锐
    effectiveDefense = ApplyArmorBreak(effectiveDefense, ctx.Target); // 破防
    effectiveDefense = Math.Max(0, effectiveDefense);
    damage = Math.Max(1, damage - effectiveDefense); // 最低造成1伤害
    // 例: 72 - 5(防御,破防后) = 67

    // ── 步骤6: 目标护盾吸收 ──
    if (ctx.Target.Shield > 0)
    {
        int absorbed = Math.Min(ctx.Target.Shield, damage);
        ctx.Target.Shield -= absorbed;
        damage -= absorbed;
    }
    // 例: 护盾10吸收10 → 剩余伤害57 → 护盾归0

    // ── 步骤7: 最终HP扣减 ──
    if (damage > 0)
    {
        ctx.Target.HP -= damage;
    }

    return damage; // 实际扣血量
}
```

### 1.2 公式速查表

| 步骤 | 公式 | 备注 |
|------|------|------|
| 基础伤害 | `card.damage` | 卡牌面板值 |
| 力量加成 | `(base + flatPower) × (100 + pctPower) / 100` | 先加法后乘法 |
| 暴击 | `damage × critMultiplier / 100` | 概率触发，默认150% |
| 倍率 | `damage × multiplier / 100` | 不动明王斩等 |
| 防御减免 | `max(1, damage - effectiveDefense)` | 最低1伤害 |
| 护盾吸收 | `min(shield, damage)` | 护盾归0后溢出伤害扣HP |
| 最终扣血 | `target.HP -= remainingDamage` | — |

## 二、防御力计算

```csharp
public int GetCurrentDefense(this Combatant target)
{
    int baseDefense = target.BaseDefense;

    // 1. 岩甲层数 (永久加成)
    baseDefense += target.StoneArmorStacks; // 每层+1

    // 2. 防御修饰器 (FLAT_ADD)
    int flatDef = target.GetModifierSum(StatType.DEFENSE, Operation.FLAT_ADD);
    baseDefense += flatDef;

    // 3. 防御修饰器 (PCT_ADD) — 石皮术等
    int pctDef = target.GetModifierSum(StatType.DEFENSE, Operation.PCT_ADD);
    baseDefense = baseDefense * (100 + pctDef) / 100;

    return Math.Max(0, baseDefense);
}
```

### 2.1 破防计算

```csharp
int ApplyArmorBreak(int defense, Combatant target)
{
    int breakStacks = target.GetStatusStacks("ArmorBreak");
    // 1层破防: 防御×50%
    // 2层破防: 防御×25%
    // N层破防: 防御×(50%^N)
    for (int i = 0; i < breakStacks; i++)
    {
        defense = defense * 50 / 100;
    }
    return defense;
}
```

## 三、灼烧/中毒结算

### 3.1 灼烧（有持续时间，自动消失）

```csharp
void ProcessBurnStartOfTurn(Combatant target)
{
    int totalBurnDamage = 0;
    foreach (var burn in target.StatusEffects.Where(s => s.id == "Burn"))
    {
        // 灼烧伤害 = 层数 × 每层伤害(默认1)
        // 火焰增幅等修饰器可增加每层伤害
        int perStackDamage = 1 + target.GetModifierSum(StatType.BURN_DAMAGE, Operation.FLAT_ADD);
        totalBurnDamage += burn.stacks * perStackDamage;

        // 灼烧有持续时间，每回合-1
        burn.duration--;
        if (burn.duration <= 0)
            target.RemoveStatus(burn);
    }

    // 灼烧伤害无视护盾和防御（直接扣HP）
    target.HP -= totalBurnDamage;
}
```

### 3.2 中毒（无持续时间，永久存在直到被清除/引爆）

```csharp
void ProcessPoisonStartOfTurn(Combatant target)
{
    // 中毒伤害 = 总层数 × 每层伤害(默认1)
    int stacks = target.GetStatusStacks("Poison");
    int perStackDamage = 1 + target.GetModifierSum(StatType.POISON_DAMAGE, Operation.FLAT_ADD);

    // 毒王领域等可让中毒伤害翻倍
    int multiplier = target.GetModifierSum(StatType.POISON_MULTIPLIER, Operation.PCT_ADD);
    int totalDamage = stacks * perStackDamage * (100 + multiplier) / 100;

    // 中毒伤害无视护盾和防御（直接扣HP）
    target.HP -= totalDamage;

    // 中毒不自动衰减（与灼烧的关键区别）
    // 只有毒爆术等卡牌才会消耗中毒层数
}
```

## 四、护盾结算规则

| 规则 | 说明 |
|------|------|
| **获得护盾** | `target.Shield += amount` |
| **护盾吸收** | 先吸收护盾，溢出伤害扣HP |
| **回合开始清0** | 默认护盾不跨回合（玄黄不灭体除外） |
| **护盾不叠加防御** | 护盾是独立缓冲层，不参与防御力计算 |
| **护盾上限** | 无上限（但实际受灵力经济约束） |

```
伤害结算顺序:
  伤害 → 减去防御力 → 剩余伤害先打护盾 → 护盾破后打HP

  例: 敌人攻击20
  玩家: 防御5, 护盾10, HP80
  结算: 20-5=15 → 护盾吸收10(护盾归0) → 5伤害打HP → HP=75
```

## 五、灵力结算规则

```csharp
// 灵力计算
public int GetCurrentEnergy(Combatant player)
{
    int baseEnergy = player.BaseEnergy; // 炼气3/筑基4/金丹5/元婴6/化神7

    // 冰冻: 每层-1灵力
    int freezeStacks = player.GetStatusStacks("Freeze");
    baseEnergy -= freezeStacks;

    // 道基树加成
    baseEnergy += player.DaoTreeEnergyBonus;

    // 法宝加成(聚灵阵: 首回合+1)
    if (player.IsFirstTurn && player.HasRelic("relic_spirit_array"))
        baseEnergy += 1;

    return Math.Max(0, baseEnergy);
}
```

| 规则 | 说明 |
|------|------|
| **每回合刷新** | 灵力完全刷新，不累积 |
| **冰冻减灵力** | 每层冰冻-1灵力(当前回合) |
| **增元丹/聚灵术** | 临时增加灵力(当前回合额外，不改变上限) |
| **灵力不为负** | 最低0 |
| **0费牌** | 不消耗灵力但占手牌位 |

## 六、特殊效果结算优先级

当多个效果同时触发时，按以下优先级处理：

```
优先级从高到低:
  1. 免疫 (不灭剑体/万毒不侵) — 直接取消伤害
  2. 闪避 (幻影剑步/闪电步) — 取消单次攻击
  3. 免死 (不灭金丹/不死魔身) — 致命伤害保留1HP
  4. 伤害减免 (护心镜首伤-50%) — 在防御计算前
  5. 防御力 — 减少伤害
  6. 护盾 — 吸收伤害
  7. 反击 — 受到攻击后触发(不论是否被护盾吸收)
  8. 灼烧/中毒 — 回合开始时触发(独立于攻击)
```

### 6.1 反击结算

```csharp
void OnDamageTaken(Combatant target, Combatant attacker, int damage)
{
    // 反击在受到攻击后触发(不论伤害是否被护盾吸收)
    // 反击伤害 = 反击层数 × 每层伤害
    int retaliateStacks = target.GetStatusStacks("Retaliate");
    if (retaliateStacks > 0)
    {
        int perStackDamage = target.GetRetaliateDamage(); // 默认5
        int totalRetaliate = retaliateStacks * perStackDamage;

        // 反击伤害也走完整伤害结算链(可暴击/被防御/被护盾吸收)
        ResolveDamage(new DamageContext
        {
            BaseDamage = totalRetaliate,
            Attacker = target,  // 反击者是"被攻击者"
            Target = attacker   // 反击打向"攻击者"
        });

        // 反击层数-1
        target.ReduceStatusStacks("Retaliate", 1);
    }
}
```

## 七、概率判定规则

```csharp
bool RollProbability(int probabilityPercent, Combatant roller)
{
    // 概率上限100%
    probabilityPercent = Math.Min(100, probabilityPercent);

    // 天雷引等概率强化
    probabilityPercent += roller.GetModifierSum(StatType.PROBABILITY_BONUS, Operation.FLAT_ADD);
    probabilityPercent = Math.Min(100, probabilityPercent);

    // 雷灵珠: 每场战斗首次失败改为成功
    if (roller.HasRelic("relic_thunder_pearl") && !roller.ProbabilityRollUsed)
    {
        bool result = rng.Next(0, 100) < probabilityPercent;
        if (!result) // 失败
        {
            roller.ProbabilityRollUsed = true;
            return true; // 改为成功
        }
        return result;
    }

    // 雷帝降临: 所有概率变为100%
    if (roller.HasStatus("ThunderEmperor"))
        return true;

    return rng.Next(0, 100) < probabilityPercent;
}
```

## 八、结算顺序总图

```
┌─ 回合开始 ──────────────────────────────────┐
│ 1. 清除上回合护盾 (玄黄不灭体除外)            │
│ 2. 灼烧/中毒 结算 (直接扣HP, 无视防御护盾)    │
│ 3. 生生不息/生命之泉 等持续回复 结算          │
│ 4. 检测死亡 (中毒/灼烧致死)                   │
│ 5. 灵力刷新 (基础值 - 冰冻 + 临时加成)        │
│ 6. 抽牌至手牌上限                            │
└──────────────────────────────────────────────┘
                    ↓
┌─ 玩家行动阶段 ───────────────────────────────┐
│ 7. 玩家选牌 → 扣灵力                         │
│ 8. 攻击牌: 走伤害结算链(步骤1-7)              │
│ 9. 防御牌: 获得护盾/防御加成                  │
│ 10. 状态牌: 施加buff/debuff到修饰器系统       │
│ 11. 卡牌进入弃牌堆(或消耗堆)                  │
│ 12. 重复7-11直到玩家结束回合                  │
└──────────────────────────────────────────────┘
                    ↓
┌─ 敌人行动阶段 ───────────────────────────────┐
│ 13. 敌人按意图执行                            │
│ 14. 敌人攻击: 走伤害结算链(玩家是目标)        │
│ 15. 玩家受击: 触发反击/闪避/免死              │
│ 16. 多个敌人依次行动(间隔0.5s)                │
└──────────────────────────────────────────────┘
                    ↓
┌─ 回合结束 ───────────────────────────────────┐
│ 17. 回合结束时触发的效果(如烈焰印记引爆)      │
│ 18. 未用手牌进入弃牌堆                        │
│ 19. 持续时间类状态 duration-1, 到期移除       │
│    (灼烧/破防/冰冻/强化 等会自动到期)         │
│ 20. 检测死亡                                 │
└──────────────────────────────────────────────┘
```
