### 1.2 UI层级

```
TEngine UILayer 定义:
  - FullScreen  → 战斗/地图/主菜单(全屏覆盖)

  - Widget      → HP条/灵力条/手牌区(战斗内组件)
```

### 2.3 交互流程

```
玩家回合操作流程:

1. 自动抽牌 → 卡牌从右侧飞入手牌区(0.3s动画)
2. 玩家观察 → 敌人意图、手牌、灵力
3. 点击手牌 → 卡牌上浮+选中状态
4. 点击目标 →
   - 攻击牌: 点击敌人 → 飞向敌人 → 伤害数字弹出
   - 防御牌: 自动作用于自身 → 护盾数字更新
   - AOE牌: 自动作用于全体 → 全体伤害数字
5. 卡牌动画 → 打出的卡牌飞向弃牌堆(0.2s)
6. 灵力更新 → 灵力宝石数字减少
7. 重复3-6 → 直到灵力耗尽或玩家点击"结束回合"
8. 结束回合 → 敌人执行意图 → 新回合开始

关键延迟:
  - 卡牌飞入: 0.3s
  - 伤害数字弹出: 0.2s显示 + 0.5s飘字消失
  - 敌人行动间隔: 0.5s(多个敌人时)
  - 回合切换: 0.3s过渡
```

### 2.4 战斗动画规范

| 事件 | 动画 | 时长 | 音效 |
|------|------|------|------|
| 抽牌 | 卡牌从右侧滑入 | 0.3s | 翻牌声 |
| 打出卡牌 | 卡牌飞向目标+放大 | 0.2s | 对应功法音效 |
| 造成伤害 | 目标抖动+红色数字弹出 | 0.2s+0.5s | 击中声 |
| 获得护盾 | 蓝色光效+数字 | 0.3s | 金属声 |
| HP减少 | HP条递减+红色闪烁 | 0.3s | 受击声 |
| 敌人死亡 | 淡出+碎裂效果 | 0.5s | 死亡声 |
| 状态施加 | 图标弹入目标头顶 | 0.3s | 对应属性音效 |
| 回合切换 | 屏幕轻微暗化0.1s | 0.3s | 钟声 |
