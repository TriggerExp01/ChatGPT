# 敌人设计 · 炼气期 + 筑基期

> **设计原则**：敌人是玩家的"老师"——每个敌人教授一个策略课程。敌人意图完全可见。  
> **数值基准**：以剑宗初始牌组（12张凡品）能稳定通过炼气期普通战斗为基准。

---

## 一、炼气期敌人

### 炼气期数值基准

| 参数 | 普通 | 精英 | Boss |
|------|------|------|------|
| HP | 30-50 | 55-75 | 110-160 |
| 伤害/回合 | 5-8 | 8-12 | 12-18 |
| 防御 | 0-1 | 1-3 | 2-4 |
| 灵力/回合 | 3 | 3 | 3 |
| 掉落灵石 | 10-15 | 20-30 | 35-50 |
| 掉落稀有度 | 凡品 | 灵品 | 灵品+法宝 |

### 普通敌人 (4种)

#### 1. 石魔
```
HP: 40 | 防御: 2 | 灵力: 3
────────────────────────────
意图模式 (循环):
  回合1: 🗡️ 攻击 6
  回合2: 🛡️ 防御 获得5护盾
  回合3: 🗡️ 攻击 8
  重复...

教授课程: "防御可以抵挡攻击"——第一次看到敌人防御时，玩家学会护盾的概念。
设计要点: 故意在防御后出重击，让玩家看到"如果刚才打了破防..."的可能性。
```

#### 2. 火蝠
```
HP: 32 | 防御: 0 | 灵力: 3
────────────────────────────
意图模式 (循环):
  回合1: 🗡️ 攻击 4 + 🔥 施加1层灼烧(2回合)
  回合2: 🗡️ 攻击 4 + 🔥 施加1层灼烧(2回合)
  回合3: ⬆️ 强化 下回合攻击+4
  回合4: 🗡️ 攻击 8(强化后)
  重复...

教授课程: "灼烧是延迟伤害"——玩家第一次接触DOT机制。学会计算"现在受到4伤害+下回合2伤害=总6伤害"。
设计要点: 火蝠是火云宗机制的"敌人教学版"。
```

#### 3. 石灵龟
```
HP: 50 | 防御: 3 | 灵力: 3
────────────────────────────
意图模式 (循环):
  回合1: 🛡️ 防御 获得8护盾
  回合2: 🗡️ 攻击 5
  回合3: 🛡️ 防御 获得8护盾
  回合4: 🗡️ 攻击 5
  重复...

教授课程: "高防御敌人需要破防/锋锐"——剑宗的破甲符在这里大放异彩。
设计要点: 故意设计成让没有破防手段的牌组感到"刮痧"。
```

#### 4. 三眼灵猴
```
HP: 35 | 防御: 0 | 灵力: 3
────────────────────────────
意图模式 (随机):
  40%: 🗡️ 攻击 5
  30%: 🗡️🗡️ 二连击 3×2
  20%: ⬆️ 闪避 下回合获得1次闪避
  10%: 🛡️ 防御 获得3护盾

教授课程: "多段攻击的存在"——让玩家看到"攻击可以不止一段"。
         同时引入闪避概念。
设计要点: 行为随机但每种意图都弱——让玩家在安全环境中体验不确定性。
```

         同时首次引入AOE攻击，让玩家需要群体防御。
设计要点: 召唤的小石魔与普通石魔呼应——玩家已经认识这种敌人。

#### 6. 火蝠王
```
HP: 55 | 防御: 1 | 灵力: 4
────────────────────────────
意图模式 (循环):
  回合1: 🔥 火雨 全体3伤害+全体灼烧1层(2回合)
  回合2: 🔥🔥 灼烧爆发 引爆全场灼烧(不移除)+施加1层灼烧
  回合3: 🗡️ 攻击 10

  重复...

设计要点: 回合2的引爆是设计亮点——如果玩家前两回合没防御，灼烧引爆会很痛。
```

### Boss (2种，每Run随机1种)

#### 7. 守山灵兽 · 石猿王
```
HP: 140 | 防御: 4 | 灵力: 3
────────────────────────────
Boss特殊: 血量低于50%时进入狂暴状态（攻击+5，防御-2）

意图模式:
  回合1: 🗡️ 重击 12
  回合2: 🗡️ 攻击 8 + 🛡️ 获得6护盾
  回合3: ⬆️ 咆哮 获得力量+5(永久)
  回合4: 🗡️🗡️ 双拳 10×2
  回合5: 🛡️ 防守姿态 获得15护盾
  重复1-5

  狂暴后(HP<50%):
  回合N: 🗡️💢 狂怒连击 7×3
  回合N+1: 🗡️💢 狂怒重击 20

教授课程: "Boss有阶段转换"——血量低于50%触发新行为。
         玩家需要为Boss的大招回合保留防御资源。
         回合3的咆哮是"必须打断或承受"的威胁。
设计要点: 石猿王是"检验你是否学会了破防+防御"的综合考试。
```

#### 8. 心魔 · 幻影剑客
```
HP: 120 | 防御: 2 | 灵力: 4
────────────────────────────
Boss特殊: 每3回合复制玩家上回合打出的最后一张牌并打出

意图模式:
  回合1: 🗡️ 剑击 10
  回合2: 🛡️ 剑御 获得8护盾 + 施加1层剑气印记
  回合3: 📋 复制 打出玩家上回合最后一张牌的复制版

         同时也教授了"剑气印记→回报"的剑宗机制。
设计要点: 回合3的复制机制是核心创意——玩家会惊喜地看到"原来我的牌这么强/这么弱"。

```
HP: 55 | 防御: 2 | 灵力: 4
────────────────────────────
意图模式 (循环):

设计要点: 冰冻让玩家的灵力从4变成3——刚好回到炼气期水平，制造"退化感"。

### Boss (2种，每Run随机1种)

#### 15. 护山神兽 · 冰焰麒麟
```
HP: 200 | 防御: 5 | 灵力: 5
────────────────────────────
Boss特殊: 奇数回合冰属性，偶数回合火属性。
         冰回合: 防御+3 / 火回合: 攻击+5

意图模式:
  回合1(冰): ❄️ 寒冰风暴 全体8伤害 + 全体冰冻1层
  回合2(火): 🔥 烈焰风暴 全体10伤害 + 全体灼烧1层(3回合)
  回合3(冰): ❄️ 绝对零度 15伤害 + 冰冻2层(单体)
  回合4(火): 🔥 焚天 18伤害(单体)
  回合5(冰): 🛡️ 冰壁 获得25护盾
  回合6(火): 🔥💥 冰火交融 引爆所有灼烧+所有冰冻伤害合并为即时伤害(全体)
  重复1-6

教授课程: "冰火双属性Boss"——玩家需要灵活切换策略。
         冰回合=囤防御，火回合=囤护盾/回复。
         回合6的冰火交融是终极考验——如果玩家没有处理好灼烧和冰冻的层数，会受到巨大伤害。
设计要点: 这个Boss同时测试了炼气期(灼烧)和筑基期(冰冻)的机制理解。
```

#### 16. 心魔 · 镜像道人
```
HP: 180 | 防御: 3 | 灵力: 5
────────────────────────────
Boss特殊: 开局复制玩家的牌库！使用玩家的牌对抗玩家。
         每5回合重新复制一次(反映玩家当前的牌库状态)。

意图模式:
  使用玩家牌库中的牌，由AI控制（偏好：高费牌>稀有牌>攻击牌）
  灵力=5，手牌上限=6
  
  特殊: 每5回合施放 "道心拷问": 造成玩家牌库数量×0.5的伤害(最少5，最多25)
        这意味着牌库越大受到伤害越高——教玩家"精简牌库"的价值

教授课程: "精简牌库的重要性"——牌库越大，道心拷问伤害越高。
         玩家第一次从"敌人"角度看到自己牌库的质量。
         "原来我的牌库里有这么多没用的牌"——这是游戏最深刻的教训之一。
设计要点: 这是整个游戏最"meta"的Boss——它不测试你的操作，而是测试你的构筑能力。
         同时是"跳过"机制的最强教学工具。
```

## 三、敌人设计总览

### 机制引入曲线

```
炼气期:
  战斗1-2: 基础攻击/防御 (石魔)
  战斗3-4: DOT机制 (火蝠)
  战斗5-6: 高防御敌人 (石灵龟)
  战斗7-8: 多段攻击+闪避 (三眼灵猴)
  精英:   召唤物 (石魔统领) / DOT爆发 (火蝠王)
  Boss:   阶段转换 (石猿王) / 机制复制 (幻影剑客)

筑基期:
  战斗1-2: 冰冻debuff (冰霜蛇妖)
  战斗3-4: 镜像对决 (筑基修士)
  战斗5-6: 中毒机制 (毒藤妖)
  战斗7-8: 闪避+快节奏 (风灵鸟)
  精英:   双行动 (双头冰火蟒) / 金丹预览 (金丹散修)
  Boss:   冰火双属性 (冰焰麒麟) / 牌库检查 (镜像道人)
```

### 敌人设计原则总结

1. **每个敌人教一件事** — 不做"什么都有的万金油敌人"
2. **先安全体验，后高压测试** — 新机制先在普通敌人中低伤害引入，精英/Boss再提高压力
3. **敌人是玩家的镜子** — 筑基修士用剑宗combo、镜像道人复制牌库
4. **意图可见 = 公平** — 所有敌人的行为模式有规律，玩家可以学习
5. **克制与反克制** — 每种敌人有弱点策略，没有"万能解法"
