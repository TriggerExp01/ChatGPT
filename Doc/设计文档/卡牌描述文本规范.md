## 一、核心原则

| 原则 | 说明 | 正例 | 反例 |
|------|------|------|------|
| **简洁** | 一句话说清效果，不超过20字 | 造成8伤害 | 对目标敌人造成8点物理伤害 |
| **数字突出** | 关键数字用特殊标记 | 造成 **8** 伤害 | 造成8伤害 |
| **无废话** | 不写"对敌人造成"——默认就是打敌人 | 造成8伤害 | 对敌人造成8伤害 |
| **术语一致** | 同一机制永远用同一个词 | 灼烧1层(2回合) | 燃烧1层(2回合) ← 不一致 |
| **省略默认值** | 默认目标=单体敌人，不写"单体" | 造成8伤害 | 对单体敌人造成8伤害 |

## 三、描述结构顺序

一张卡有多个效果时，按以下顺序描述：

```
1. 代价（失去HP/消耗手牌/消耗）
2. 即时伤害
3. 即时防御（护盾）
4. 即时回复
5. 施加状态（debuff给敌人）
6. 获得状态（buff给自己）
7. 抽牌/灵力
8. 持续效果（生生不息等）
9. 条件效果（"如果目标有灼烧..."）
```

**示例**：

```
血祭掌:
  失去3HP。造成12伤害。
  ↓ 代价在前，伤害在后

焚天掌:
  造成12伤害 + 施加2层灼烧(3回合)。
  ↓ 伤害在前，状态在后

金钟罩:
  获得12护盾 + 本回合防御+3。
  ↓ 防御在前，buff在后

天魔解体:
  失去10HP。本回合灵力+3、力量翻倍(所有伤害×2)。
  ↓ 代价→资源→buff
```

## 四、标点与格式

| 规则 | 正例 | 反例 |
|------|------|------|
| 多效果用 `+` 连接 | 造成8伤害 + 获得5护盾 | 造成8伤害，获得5护盾 |
| 持续时间用括号 | 灼烧1层(2回合) | 灼烧1层持续2回合 |
| 条件用句号分隔 | 造成4伤害。如果目标有灼烧，额外造成4伤害。 | 造成4伤害如果目标有灼烧额外造成4伤害 |
| 数值不加"点" | 造成8伤害 | 造成8点伤害 |
| 百分比用% | 50%概率眩晕 | 50%几率眩晕 |
| 不用"的" | 造成8伤害 | 造成8的伤害 |
| 句末不加句号(单效果) | 造成8伤害 | 造成8伤害。 |
| 句末加句号(多效果最后) | 造成4伤害。如果目标有灼烧，额外造成4伤害。 | — |

## 五、升级树描述规范

升级后的卡牌描述**只写变化的部分**，不重复不变的效果。

```
正例:
  原牌: 造成8伤害
  升级: 造成11伤害 (+3)

  原牌: 造成3伤害 + 施加1层破防(2回合)
  升级: 造成3伤害 + 施加2层破防(2回合) (+1层)

反例:
  原牌: 造成8伤害
  升级: 造成11伤害 (重复了"伤害"等不变内容)
```

升级树分支用 `→` 表示：
```
剑气诀 (1灵/8伤)
├─ 1A: 追魂剑气 → 伤害+3
└─ 1B: 灵动剑气 → 灵力消耗-1
```

## 六、法宝描述规范

法宝描述用**一句话**说清被动效果：

```
正例:
  储物袋: 牌库上限+3
  天道石: 每回合额外抽1张牌
  不灭金丹: 受到致命伤害时保留1HP，每Run1次

反例:
  储物袋: 增加你的牌库上限3点 (太啰嗦)
  天道石: 在每个回合开始的时候你可以多抽一张牌 (太啰嗦)
```

## 七、秘境事件描述规范

事件描述分三部分：

```
【标题】简洁有氛围感
【描述】2-3句话设定场景，末尾给选择压力
【选项】动词开头，说明代价和收益

示例:
【标题】妖兽巢穴
【描述】一只受伤的妖兽守护着什么，它注意到你了。
【选项A】⚔️ 战斗：精英战斗，胜利获得圣品法宝
【选项B】🩹 救治：失去20HP，获得仙品卡牌
【选项C】🚶 离开
```

**规范**：
- 标题≤4字
- 描述≤50字
- 选项格式：`图标 动作：代价，收益`
- 每个选项一行
- "离开"选项永远在最后
