# 药王谷 · 完整卡牌池设计

> **项目适配说明**：本文档由 `C:/Users/hirusumi/Downloads/仙途天命_完整设计文档.md` 拆分并适配到当前 Unity + TEngine 项目。实现以 `D:/Work/Unity_Project/TEngine_Game` 仓库为准；设计文档统一存放在 `Doc/设计文档`。
> **拆分日期**：2026-06-20


> **门派定位**：中毒堆积 + 持续回复 + 持久消耗战
> **设计哲学**：剑宗追求"这一回合击杀"，火云宗享受"看着敌人被烧死"，药王谷信奉"我死不了，你总会死"。药王谷的策略核心是**时间是你的朋友**——战斗越长，中毒和回复的优势越大。
> **核心机制关键词**：中毒、回复、生生不息、毒爆、净化
> **卡牌总数**：27张门派专属

---

## 机制关键词说明

| 关键词 | 触发/效果 | 设计意图 |
|--------|----------|----------|
| **中毒** | 每回合开始造成N点伤害，N=中毒层数。不自动衰减。上限99层。 | 核心DOT——与灼烧不同，中毒是"指数累积"的 |
| **生生不息** | 每回合开始自动恢复N点HP，持续M回合 | 被动回复——让时间站在你这边 |
| **毒爆** | 消耗目标身上所有中毒层数，造成中毒层数×N的即时伤害 | 中毒体系的爆发手段——"不想等了就现在爆" |
| **净化** | 清除自身所有负面状态 | 对策能力——专门克制灼烧/冰冻/破防/中毒 |
| **吸灵** | 造成伤害的同时恢复HP | 攻防一体——药王谷的核心生存手段 |

---

#### 1. 毒藤术
```
稀有度: 凡品 | 灵力: 1 | 类型: 攻击功法·木
效果: 造成 3 伤害 + 施加2层中毒
设计意图: 基准中毒牌——直伤极低但中毒累积快。1灵力总期望=3+2×(战斗剩余回合)。
        战斗持续5回合=3+2×5=13总伤，远超1灵力基准8。
五行: 木
```

**升级树**：
```
毒藤术 (1灵/3伤/中毒2层)
├─ 1A: 毒蔓术 → 中毒+1层 (3伤/中毒3层)
│  ├─ 2A: 毒林术 → 中毒+2层 (3伤/中毒5层)
│  └─ 2B: 毒棘术 → 直伤+5 (8伤/中毒2层)
│
└─ 1B: 速发毒藤 → 灵力消耗-1 (0灵/3伤/中毒2层)
   ├─ 2C: 毒藤缠绕 → 额外施加1层破防
   └─ 2D: 毒藤蔓延 → 对全体敌人施加1层中毒
```

## 七、三大门派对比

| 维度 | 剑宗 | 火云宗 | 药王谷 |
|------|------|--------|--------|
| **核心伤害** | 物理直伤 | 灼烧DOT+引爆 | 中毒DOT+毒爆 |
| **伤害速度** | 立即 | 中等(可引爆加速) | 慢(但指数增长) |
| **生存方式** | 护盾 | 护盾+灼烧反伤 | 回复+吸血 |
| **战斗偏好** | 快速解决 | 中速积累→爆发 | 持久消耗 |
| **对单能力** | 极强 | 强 | 中(但持续越久越强) |
| **对多能力** | 中 | 极强 | 强(中毒分散) |
| **新手友好** | 高 | 中 | 低(需要理解时间价值) |
| **高手上限** | 高 | 极高 | 极高(时机管理) |
| **标志感受** | "一剑破万法" | "看着他们烧成灰" | "我死不了，你总会死" |
| **克星敌人** | 高防御(石灵龟) | DOT免疫(不灭骨龙) | 爆发型(雷鹰) |
