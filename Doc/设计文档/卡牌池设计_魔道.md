# 魔道 · 完整卡牌池设计

> **项目适配说明**：本文档由 `C:/Users/hirusumi/Downloads/仙途天命_完整设计文档.md` 拆分并适配到当前 Unity + TEngine 项目。实现以 `D:/Work/Unity_Project/TEngine_Game` 仓库为准；设计文档统一存放在 `Doc/设计文档`。
> **拆分日期**：2026-06-20


> **门派定位**：HP作为资源 + 高风险高回报 + 禁术爆发
> **设计哲学**：魔道是唯一一个"伤害自己来获得力量"的门派。其他门派保护HP，魔道挥霍HP。魔道玩家享受"我剩1血但我一回合打了60伤害"的极致赌徒快感。
> **核心机制关键词**：血祭、献祭、噬血、禁术、癫狂
> **卡牌总数**：27张门派专属

---

## 机制关键词说明

| 关键词 | 触发/效果 | 设计意图 |
|--------|----------|----------|
| **血祭** | 失去N点HP作为代价，换取强力效果 | HP是资源——魔道的核心交易 |
| **献祭** | 消耗手牌/牌库中的牌作为代价 | 牌也是资源——牺牲牌库质量换即时力量 |
| **噬血** | 造成伤害时恢复造成伤害一定比例的HP | 攻防一体——打得越狠回得越多 |
| **禁术** | 效果极强但有严重代价(失血/消耗/永久削弱) | 高风险高回报——魔道的灵魂 |
| **癫狂** | 每损失10%最大HP，所有伤害+5% | 低血量=高伤害——越危险越强大 |

## 一、攻击功法 (13张)

### 凡品 (5张)

---

#### 1. 血祭掌
```
稀有度: 凡品 | 灵力: 1 | 类型: 攻击功法·魔
效果: 失去 3 HP。造成 12 伤害。
设计意图: 魔道基准牌——1灵力+3HP换12伤。比剑气诀多4伤但代价是3HP。
        教玩家"HP是可以花的"。
五行: 暗
```

**升级树**：
```
血祭掌 (1灵/失3HP/12伤)
├─ 1A: 血祭掌·强 → 伤害+4 (失3HP/16伤)
│  ├─ 2A: 血祭掌·极 → 伤害+4 (失3HP/20伤)
│  └─ 2B: 血祭掌·廉 → 失血-1 (失2HP/12伤)
│
└─ 1B: 血祭掌·噬 → 造成伤害的30%转化为HP回复(净失血减少)
   ├─ 2C: 血祭掌·速 → 灵力消耗-1 (0灵/失3HP/12伤)
   └─ 2D: 血祭掌·狂 → 失血+3但伤害+8 (失6HP/20伤)
```

#### 2. 噬血爪
```
稀有度: 凡品 | 灵力: 1 | 类型: 攻击功法·魔
效果: 造成 6 伤害 + 恢复造成伤害的50%HP(恢复3)。
设计意图: 魔道的攻防一体——打6回3=净输出3伤+3回复。
        与药王谷吸灵术对称但更偏攻击。
五行: 暗
```

**升级树**：
```
噬血爪 (1灵/6伤/回复50%)
├─ 1A: 噬血·强 → 伤害+4 (10伤/回复5)
│  ├─ 2A: 噬血·极 → 回复比例+25% (回复75%)
│  └─ 2B: 噬血·连 → 攻击2次(各6伤/各回复3)
│
└─ 1B: 噬血·速 → 灵力消耗-1 (0灵/6伤/回复50%)
   ├─ 2C: 噬血·广 → 对全体敌人造成3伤害/回复总伤50%
   └─ 2D: 噬血·狂 → 伤害+6但失去3HP (12伤-3HP/回复6)
```

```
五行: 暗

```
