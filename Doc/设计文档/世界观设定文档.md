## 一、世界概述

### 1.1 一句话概述

> 九州大陆，灵气复苏。天道崩坏后，修仙者不再飞升——取而代之的是无尽的天劫。你是一名初入仙途的修士，在崩坏的修仙世界中寻找飞升之路。

### 1.2 核心设定：天道崩坏

万年前，九州大陆的修仙者可以修炼至渡劫飞升，位列仙班。

但某一天，天道崩坏了。

没有人知道原因。仙界关闭了大门，飞升通道断绝。从那以后，无论修士修为多高，都无法飞升——天劫不再是飞升的考验，而是**无尽的惩罚**。

天道崩坏后：
- **灵气变得狂暴**——修炼更容易，但走火入魔也更常见
- **天劫不再停息**——每次突破境界都会引来天劫，且越来越强
- **仙界遗迹出现**——古仙人的洞府、法宝、功法散落九州
- **修仙界分裂**——正道魔道之争白热化，资源争夺加剧

玩家就生活在这个时代。

## 二、六大门派

### 2.1 剑宗 · 万剑山

> **"以剑入道，一剑破万法。"**

| 项目 | 内容 |
|------|------|
| **位置** | 中州·万剑山 |
| **历史** | 九州最古老的剑修门派，传承万年。天道崩坏前就以剑道闻名，崩坏后依然坚守正道剑修的信念 |
| **门派特色** | 纯粹的剑修——不修法术、不炼丹药，只修剑。认为剑是万法之基 |
| **核心理念** | 一剑破万法——复杂的问题用最简单的方式解决 |
| **视觉风格** | 青灰色调、简洁利落、剑形纹饰 |
| **代表人物** | 掌门"剑圣"白无尘——据说他曾在天道崩坏时一剑劈开天劫(无人证实) |
| **玩家身份** | 万剑山外门弟子，刚通过入门试炼获得修炼资格 |

> **"烈火焚尽万物，灰烬中重生。"**

## 三、境界体系（与游戏机制关联）

| 境界 | 修仙设定 | 游戏机制 | 突破条件 |
|------|----------|----------|----------|
| **炼气期** | 引气入体，初步感应灵气 | Run第1层，基础灵力3 | — |
| **筑基期** | 筑就道基，正式踏入修仙 | Run第2层，灵力+1 | 击败炼气期Boss |
| **金丹期** | 结成金丹，寿元大增 | Run第3层，获得金丹被动 | 击败筑基期Boss |
| **元婴期** | 元婴出窍，神魂强大 | Run第4层，获得元婴能力 | 击败金丹期Boss |
| **化神期** | 元神化形，初步掌控天地法则 | Run第5层，神魂强化 | 击败元婴期Boss |
| **渡劫飞升** | 渡过天劫，飞升仙界 | 最终Boss战 | 击败化神期Boss |

### 3.1 金丹被动设定

金丹是修士修炼的里程碑——将全身灵气凝聚为一颗金丹，金丹的品质决定了修士的战斗风格。

游戏中表现为：金丹期突破时，从3个随机金丹被动中选择1个。每个金丹被动代表不同的"灵根"天赋：
- **火灵根**：天生亲和火属性
- **冰灵根**：天生亲和冰属性
- **雷灵根**：天生亲和雷属性
- **剑心通明**：剑道天赋异禀
- **不灭金身**：体修天赋异禀
- **毒体**：天生亲和毒属性

### 3.2 天劫设定

天道崩坏后，天劫不再是对修士的考验，而是**天道的无差别攻击**。

每次境界突破都会引来天劫。天劫的类型决定了Boss战的特殊规则：
- **九天神雷**：天道以雷电惩罚修士
- **天火焚身**：天道以烈火净化修士
- **心魔劫**：天道以心魔侵蚀修士
- **风雷劫**：天道以风雷压制修士
- **寒冰劫**：天道以寒冰封锁修士

**最终天劫**是渡劫飞升时的考验——天道会倾尽全力阻止修士飞升。

## 七、叙事融入游戏的方式

### 7.1 不做传统叙事

本游戏**不做线性剧情**。叙事通过以下方式融入：

| 方式 | 示例 |
|------|------|
| **门派背景** | 选择门派时展示背景故事(3-5句话) |
| **Boss设定** | Boss出场时显示名字+1句话设定 |
| **秘境事件文本** | 事件描述本身就是世界观碎片 |
| **卡牌名称/描述** | 功法名本身就是设定(如"万剑归宗"暗示剑宗历史) |
| **法宝描述** | 每件法宝有1句话背景(如"青冥剑——上古剑仙遗物") |
| **境界突破动画** | 突破时展示境界名称+1句话描述 |

### 7.2 留白原则

> **世界观服务于玩法，而非反之。**

- 不强加剧情给玩家——想看的看，不想看的直接跳过
- 所有叙事文本不超过3句话——不打断游戏节奏
- 留白比填满更好——"青衣道人到底是谁"不需要答案
- 让玩家通过游戏体验自己构建故事——"那次金丹雷劫流"就是玩家自己的叙事

## 八、Steam商店页素材准备

### 8.1 游戏简介(短)

> 一款东方玄幻题材的卡牌构筑Roguelite。选择六大仙门之一，收集功法卡牌、突破修仙境界、渡过天劫飞升。每次Run都是一段独一无二的修行之旅。

### 8.2 游戏简介(长)

> 天道崩坏万年，飞升之路断绝。
>
> 你是九州大陆一名初入仙途的修士。在这灵气狂暴、天劫肆虐的末世中，六大仙门各自延续着修仙的火种。
>
> **选择你的道** —— 六大门派，六种截然不同的战斗哲学。剑修一剑破万法、火修烈焰焚天、药修以毒攻毒、雷修赌命爆发、土修不破之盾、魔修以血换力。
>
> **构筑你的功法** —— 超过120张卡牌，每张可升级2次，4种成长路径。精简还是膨胀？专精还是兼修？你的牌组就是你的道。
>
> **突破你的境界** —— 从炼气到飞升，五层境界，每层天劫。境界突破带来永久的灵力、手牌、牌库成长。
>
> **渡过你的天劫** —— 每层Boss都是一场天劫。九天神雷、天火焚身、心魔劫……每种天劫都有特殊规则，考验你的构筑是否全面。
>
> **传承你的道基** —— 死亡不是结束。每次Run都会留下道基精华，永久强化你的下一次修行。
>
> 飞升之路已断，但你的仙途才刚刚开始。
