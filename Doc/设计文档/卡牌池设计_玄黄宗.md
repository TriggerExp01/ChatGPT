# 玄黄宗 · 完整卡牌池设计

> **项目适配说明**：本文档由 `C:/Users/hirusumi/Downloads/仙途天命_完整设计文档.md` 拆分并适配到当前 Unity + TEngine 项目。实现以 `D:/Work/Unity_Project/TEngine_Game` 仓库为准；设计文档统一存放在 `Doc/设计文档`。
> **拆分日期**：2026-06-20


> **门派定位**：护盾堆叠 + 防御反击 + 以守代攻
> **设计哲学**：其他门派都在想"怎么打死敌人"，玄黄宗想的是"怎么让敌人打不死我，然后反杀"。玄黄宗的玩家享受"你打我一下，我反弹你两下"的快感。
> **核心机制关键词**：护盾、岩甲、反击、不动、蓄势
> **卡牌总数**：27张门派专属

---

## 机制关键词说明

| 关键词 | 触发/效果 | 设计意图 |
|--------|----------|----------|
| **岩甲** | 永久增加防御力（本Run内） | 与护盾不同，岩甲是永久成长——时间站在你这边 |
| **反击** | 被攻击时自动对攻击者造成伤害 | 被动输出——敌人打你越多，你伤害越高 |
| **不动** | 本回合不主动攻击，下回合获得强化效果 | 以守代攻——牺牲当前输出换取更大回报 |
| **蓄势** | 护盾溢出时转化为永久强化 | 过量防御不浪费——时间投资 |
| **崩甲** | 消耗自身护盾转化为伤害 | 攻防转换——瞬间从铁桶变炮台 |

## 一、攻击功法 (11张)

### 凡品 (5张)

---

#### 1. 岩击
```
稀有度: 凡品 | 灵力: 1 | 类型: 攻击功法·土
效果: 造成 6 伤害 + 获得 1 层岩甲(防御+1，本Run永久)
设计意图: 玄黄宗基准攻击——比剑气诀少2伤但永久+1防御。
        战斗越长防御越高，体现"越打越硬"的门派特色。
五行: 土
```

**升级树**：
```
岩击 (1灵/6伤/岩甲1层)
├─ 1A: 岩击·强 → 伤害+3 (9伤/岩甲1层)
│  ├─ 2A: 岩击·极 → 岩甲+1层 (9伤/岩甲2层)
│  └─ 2B: 岩击·崩 → 伤害+5但消耗所有岩甲(每层+3伤)
│
└─ 1B: 岩击·稳 → 灵力消耗-1 (0灵/6伤/岩甲1层)
   ├─ 2C: 岩击·厚 → 岩甲+1层 (6伤/岩甲2层)
   └─ 2D: 岩击·反 → 额外获得1层反击(3伤害)
```
