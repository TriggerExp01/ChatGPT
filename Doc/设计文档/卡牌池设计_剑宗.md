# 剑宗 · 完整卡牌池设计

> **项目适配说明**：本文档由 `C:/Users/hirusumi/Downloads/仙途天命_完整设计文档.md` 拆分并适配到当前 Unity + TEngine 项目。实现以 `D:/Work/Unity_Project/TEngine_Game` 仓库为准；设计文档统一存放在 `Doc/设计文档`。
> **拆分日期**：2026-06-20


> **门派定位**：物理直伤 + 破防协同 + 剑气连击
> **设计哲学**：剑宗是游戏的**基准门派**——简单直接、容易理解、上限清晰。所有其他门派的强度都以剑宗为参照系。
> **核心机制关键词**：破防、剑气印记、连击、锋锐
> **卡牌总数**：36张（门派专属28张 + 通用丹药/法宝8张见通用池）

---

## 机制关键词说明

| 关键词 | 触发/效果 | 设计意图 |
|--------|----------|----------|
| **破防** | 目标防御力-50%，持续2回合 | 核心输出放大器——教玩家"先破后打" |
| **剑气印记** | 叠至3层时引爆，造成额外伤害 | 提供"规划连招"的策略深度 |
| **连击** | 本回合内打出第N张功法时触发额外效果 | 鼓励在同一回合集中输出 |
| **锋锐** | 无视目标N点防御 | 对抗高防御敌人的对策 |

---

#### 1. 剑气诀
```
稀有度: 凡品 | 灵力: 1 | 类型: 攻击功法·剑
效果: 造成 8 伤害
设计意图: 基准攻击牌——全游戏的伤害标尺。每张攻击牌都可以和它比较。
五行: 金
```

**升级树**：
```
剑气诀 (1灵/8伤)
├─ 1A: 追魂剑气 → 伤害+3 (1灵/11伤)
│  ├─ 2A: 破魂剑气 → 额外施加1层破防(2回合)
│  └─ 2B: 连珠剑气 → 伤害变为2×6 (总12，可分别触发连击)
│
└─ 1B: 灵动剑气 → 灵力消耗-1 (0灵/8伤)
   ├─ 2C: 无影剑气 → 额外抽1张牌
   └─ 2D: 寒光剑气 → 施加1层锋锐(无视3防御，2回合)
```
