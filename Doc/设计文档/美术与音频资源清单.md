## 七、资源命名规范

```
卡牌插画: card_<sect>_<id>.png
  例: card_sword_sword_qi_01.png

敌人立绘: enemy_<realm>_<id>.png
  例: enemy_qi_stone_golem.png

UI背景: bg_<scene>.png
  例: bg_combat_qi_refining.png

UI组件: ui_<component>_<state>.png
  例: ui_button_normal.png, ui_button_hover.png

法宝图标: relic_<id>.png
  例: relic_storage_bag.png

特效: vfx_<type>_<element>.png
  例: vfx_attack_fire_01.png

BGM: bgm_<scene>.ogg
  例: bgm_combat_boss.ogg

音效: sfx_<category>_<description>.wav
  例: sfx_card_fire_burn_01.wav
```

**格式要求**：
- 插画/图标/UI：PNG(透明背景)
- 特效：PNG序列帧 或 Unity Particle System
- BGM：OGG(循环友好)
- 音效：WAV(无压缩，Unity会自动压缩)
