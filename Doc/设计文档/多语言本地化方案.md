## 一、本地化架构

### 1.1 技术方案

使用Luban配置表的本地化功能 + TEngine资源模块管理语言资源。

```
Configs/GameConfig/
├── Localization/
│   ├── String_zh_cn.xlsx    # 简体中文(主)
│   ├── String_zh_tw.xlsx    # 繁体中文
│   └── String_en.xlsx       # 英文
```

```csharp
// 本地化访问
public static class I18n
{
    public static string Get(string key)
    {
        return ConfigSystem.GetLocalizedString(key, CurrentLanguage);
    }

    public static string Get(string key, params object[] args)
    {
        return string.Format(Get(key), args);
    }
}

// 使用示例
text.text = I18n.Get("CARD_SWORD_QI_NAME");        // "剑气诀"
desc.text = I18n.Get("CARD_SWORD_QI_DESC");        // "造成8伤害"
damage.text = I18n.Get("COMBAT_DAMAGE", 8);        // "造成8伤害" / "Deal 8 damage"
```

### 1.2 文本Key命名规范

```
格式: <模块>_<类型>_<标识符>

示例:
  CARD_<sect>_<id>_NAME        # 卡牌名
  CARD_<sect>_<id>_DESC        # 卡牌描述
  ENEMY_<id>_NAME              # 敌人名
  ENEMY_<id>_DESC              # 敌人描述
  RELIC_<id>_NAME              # 法宝名
  RELIC_<id>_DESC              # 法宝描述
  UI_<screen>_<element>        # UI文本
  ACH_<id>_NAME                # 成就名
  ACH_<id>_DESC                # 成就描述
  EVENT_<id>_TITLE             # 事件标题
  EVENT_<id>_DESC               # 事件描述
  EVENT_<id>_OPT_A             # 事件选项A
  REALM_<id>_NAME              # 境界名
  SECT_<id>_NAME               # 门派名
  SECT_<id>_DESC               # 门派描述
```

## 三、英文本地化注意事项

### 3.1 文化适配原则

| 原则 | 示例 |
|------|------|
| **不直译成语** | "一剑破万法" → "One Sword Shatters All" (非"One sword breaks ten thousand methods") |
| **保留拼音专有名词** | "Dao"(道)、"Qi"(气)、"Dan"(丹) 在英文修仙圈已通用 |
| **效果描述简洁** | 英文比中文长30-40%，UI需预留空间 |
| **数字格式** | 英文用逗号(1,000)，中文不需要 |
| **复数处理** | "Deal 8 damage"(不可数) 而非 "Deal 8 damages" |

### 3.2 卡牌名翻译示例

| 简中 | 英文 | 说明 |
|------|------|------|
| 剑气诀 | Sword Qi Strike | "诀"译为"Strike"而非"Formula" |
| 破甲符 | Armor Break Talisman | "符"译为"Talisman" |
| 焚天掌 | Heaven Burning Palm | 直译，有气势 |
| 万剑归宗 | Myriad Swords Return | "归宗"意译为"Return" |
| 剑开天门 | Sword Opens Heaven's Gate | 直译 |
| 天魔解体 | Heavenly Demon Dissolution | "解体"译为"Dissolution" |
| 三昧真火 | Samadhi True Fire | "三昧"用梵文音译Samadhi |
| 大日焚天诀 | Great Sun Heaven Burning Art | "诀"此处译为"Art" |
| 诛仙剑阵 | God-Slaying Sword Formation | "诛仙"意译 |
| 不灭金身 | Indestructible Golden Body | 直译 |

### 3.3 英文UI文本预留

英文平均比中文长30-40%，UI设计需注意：

| UI元素 | 中文预留 | 英文预留 | 处理方式 |
|--------|----------|----------|----------|
| 卡牌名 | 6字 | 20字符 | 字号自适应缩小 |
| 卡牌效果 | 15字 | 50字符 | 自动换行(最多3行) |
| 按钮文字 | 4字 | 15字符 | 按钮宽度自适应 |
| 敌人名 | 5字 | 20字符 | 字号固定，过长截断+省略号 |
| 战斗日志 | 20字/行 | 60字符/行 | 自动换行 |

## 四、字体方案

| 语言 | 字体 | 备用 | 说明 |
|------|------|------|------|
| 简体中文 | 思源黑体 | 微软雅黑 | 开源免费，覆盖全部CJK |
| 繁体中文 | 思源黑體 TC | 微软正黑体 | 繁体变体 |
| 英文 | Inter | Arial | 现代无衬线，数字清晰 |

**Unity字体方案**：
- 使用TextMeshPro + Font Asset
- 每种语言生成独立的Font Asset
- 卡牌效果文本使用TMP的自动换行和字号自适应

## 五、本地化流程

### 5.1 开发阶段

```
1. 所有文本用I18n.Get("KEY")引用，不硬编码
2. 简体中文为"主语言"，其他语言从简中翻译
3. 每次新增文本时同步更新三语Luban配表
4. CI检查: 扫描代码中所有I18n.Get调用，验证Key存在于配表中
```

### 5.2 翻译流程

```
简中(设计师编写) → 繁中(自动转换+人工校对) → 英文(专业翻译+修仙文化审校)
```

**繁体转换**：使用OpenCC做自动转换，然后人工校对修仙术语（有些词繁简有差异）。

**英文翻译**：建议找有修仙网文翻译经验的译者——普通译者会把"金丹"翻成"Golden Pill"而非修仙圈通用的"Golden Core"。

### 5.3 测试清单
