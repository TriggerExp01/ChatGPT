# 类吸血鬼幸存者阶段开发路线

## 项目目标

使用 Unity 和当前 TEngine 项目实现一个类《吸血鬼幸存者》的 2D 自动战斗肉鸽游戏。

核心体验：

- 玩家控制角色移动。
- 武器自动寻找并攻击敌人。
- 敌人从四周持续生成并追击玩家。
- 击杀敌人获得经验，升级时随机三选一。
- 随着时间推进形成武器、被动和数值构筑。

## 执行规则

1. 每次只推进一个阶段。
2. 当前阶段完成 Unity 运行验收后，再进入下一阶段。
3. 优先复用 TEngine 与当前项目已有模块。
4. 代码保持简洁，不为后续阶段提前建设复杂系统。
5. 对象池、Luban 配置化和内容扩展在核心闭环稳定后再推进。

- 敌人、掉落物和投射物实现 `IMemory`，由 TEngine `MemoryPool` 获取和释放。
