# Cultivation UIStyleGuide

## 当前风格定位

当前 Dev 分支的 UI 视觉基线按 `Cultivation / 修仙养成卡牌路线原型` 收束，用于支撑修仙、养成、路线选择、秘境事件、奖励、休息、市场、宝箱和卡牌战斗等原型流程。

这套风格不是最终商业产品方向锁死，而是当前 UGUI Prefab 的黄金样板标准。后续 UI 必须先跟随样板保持统一，再按阶段确认是否扩展或替换美术方向。

关键词：

- 东方修仙
- 玄幻养成
- 卡牌路线
- 秘境探索
- 暗色玉石
- 古铜 / 旧金描边
- 玉简 / 卷轴 / 法器感
- 低饱和、厚重、清晰
- 有主次层级
- 有游戏 UI 感

## 色彩规范

| 用途 | 建议色值 | 说明 |
|---|---:|---|
| 主背景 | `#071614` / `#0B1E1B` | 深墨绿、青黑，不使用纯黑或纯灰 |
| 背景暗角 | `#020706` | 用于边缘压暗和层次控制 |
| 主面板 | `#102A25` | 深玉色，承载主要信息 |
| 次面板 | `#1C241B` | 暗褐黑，用于角色、卡牌和列表底色 |
| 面板描边 | `#A77A34` | 旧金、铜金，不要高饱和亮黄 |
| 主强调 | `#D9B56A` | 灵光金，用于标题、主按钮、当前节点 |
| 次强调 | `#58BFA4` | 玉青，用于灵力、可交互提示 |
| 风险强调 | `#B85345` | 朱砂红，用于危险、生命损失 |
| 正文 | `#E8DFC6` | 米白，保证暗底可读 |
| 次要文字 | `#A99F86` | 灰金，用于说明和弱信息 |
| 禁用态 | `#4B5A50` | 低饱和灰绿，禁止使用默认纯灰 |

## 字号规范

目标画布为 1920x1080，字体大小按 UGUI / TMP 点数设置：

- 页面主标题：36-44。
- 面板标题：26-32。
- 卡牌标题：22-26。
- 主要数字：24-30。
- 正文：18-22。
- 次要说明：15-18。
- 按钮文字：20-24。
- 图标标签：14-16。

字号必须按信息层级统一，不允许同一区域里随机混用多个相近字号。

## 字体使用规范

- 新增 UI 文本优先使用 TextMeshProUGUI。
- Phase77A 黄金样板已引入中文 TMP 样板字体 `UnityProject/Assets/AssetRaw/Fonts/NotoSansCJKsc-VF.ttf`，用于保证中文截图可读。
- 标题优先使用更有东方气质的宋体或仿宋类字体；若项目暂无正式字体资源，可先使用 TMP 动态字体占位，并在交付说明中标注字体风险。
- 正文、数字、按钮和状态文本优先使用清晰的黑体类字体。
- 字体必须保证中文在 1920x1080 截图中清晰可读，不允许糊、挤、裁切或过小。
- 字体样式应通过字号、颜色、描边、阴影和字重建立层级，不允许随意混搭多种字体。

## 面板规范

- 主面板必须有暗色底、旧金或铜金描边、内边距和轻微阴影。
- 纯色矩形面板不能作为最终 UI；即使是暗色，也必须补足描边、暗纹、渐变、内阴影或分区层次。
- 面板内部应明确分为标题区、内容区和操作区。
- 面板之间保持统一间距，1920x1080 下大面板间距建议 24-36。
- 背景面板可以用渐变、暗纹、边缘压暗、玉石纹理占位图增强层次。
- 信息密集区域优先用分隔线、标题条和标签块区分，不直接堆白字。

## 按钮规范

- 主按钮使用旧金或灵光金强调，尺寸明显大于次按钮。
- 次按钮使用暗玉色或铜金边框，保持统一高度和圆角。
- 按钮必须规划 `normal`、`pressed`、`disabled` 状态。
- `pressed` 状态应更暗、更低或更紧，不只是颜色随机变化。
- `disabled` 状态使用低饱和灰绿，并降低文字对比，不使用 Unity 默认灰。
- 所有按钮文字必须垂直居中，左右内边距足够，不贴边。

## 卡牌规范

- 卡牌比例建议接近 5:7，黄金样板中推荐 170x238 到 190x266。
- 卡牌必须包含标题区、费用区、图标/插画占位区、类型/品质区、描述区。
- 卡牌底色使用深玉、暗褐或宣纸暗色，不使用白色方块。
- 稀有度用边框、角标或标题条区分，不只靠文字说明。
- 卡牌描述区必须有内边距，文本不能贴边或溢出。

## 路线节点规范

- 路线节点必须有图标感、边框、底色和状态区分。
- 至少区分已完成、当前、未到达三种状态。
- 当前节点使用灵光金或玉青高亮，并允许轻微发光。
- 连线使用暗金、玉青或低饱和光线，不使用普通灰线。
- 节点图标可以先用 UGUI/TMP 占位符号，但必须放在有装饰感的底座内，不能只是纯圆圈加字。

## 秘境事件弹窗规范

- 弹窗为深玉主面板，旧金描边，背景加遮罩。
- 标题区显示“秘境事件”和事件名，正文使用米白。
- 选项按钮应比普通次按钮更有事件感，可用玉简或卷轴式横条。
- 奖励预览区域必须与正文分区，不混在描述段落内。
- 默认隐藏样板也必须结构清楚，便于后续复制为正式 EventPopup。

## 奖励展示规范

- 奖励项应使用图标框 + 名称 + 简短说明。
- 稀有奖励使用边框色或角标强调。
- 奖励列表必须有统一间距和对齐。
- 不允许把奖励写成没有图标、没有边框、没有层级的纯文本列表。

## 列表规范

- 列表项高度统一，左侧图标或标识统一宽度。
- 列表项之间使用暗金细分隔线或 8-12 间距。
- 选中项要有明显底色和边框变化。
- 空列表需要有主题化空状态，不显示默认空白区域。

## 禁止事项

- 禁止使用 Unity 默认灰色按钮作为最终 UI。
- 禁止使用 Unity 默认白色 Panel 作为最终 UI。
- 禁止使用纯色矩形面板作为最终 UI。
- 禁止无描边、无层次、无间距规范的裸 UI。
- 禁止现代后台管理系统风格。
- 禁止科幻蓝白界面。
- 禁止纯黑纯灰工程 UI。
- 禁止花哨但不可读的 UI。
- 禁止恢复旧肉鸽 UI、旧 Battle 系列 UI 或 `Roguelike_StarUI_*` 资源。
- 所有新增 UI Prefab 必须截图验收。
- 没有黄金样板前，不允许批量制作同类 UI。
