# UI 截图验收标准

## 基本要求

所有新增 UGUI Prefab 在提交前必须提供截图证据。当前 Cultivation 黄金样板截图固定输出到：

```text
Doc/UI截图验收/MainRunWindow_Golden_Phase77A.png
```

截图目标分辨率为 1920x1080。若因 Unity 或 MCP 限制使用替代截图方式，必须在交付说明中写明原因和实际截图方式。

## 一票否决项

截图出现以下情况，不能通过：

- 默认灰色按钮。
- 默认白色面板。
- 纯色矩形面板。
- 字体大小混乱。
- 元素贴边。
- 间距不统一。
- 缺少标题区、内容区、操作区。
- 按钮像后台管理系统。
- 看不出修仙 / 卡牌 / 游戏感。
- 背景太空。
- 对比度不足。
- 重要按钮不突出。
- 面板没有层次。
- 卡牌像白色文字框。
- 路线节点像普通圆点流程图。
- 没有截图证据。

## Cultivation 黄金样板检查项

### 背景

- 背景不是纯黑、纯灰或默认白图。
- 有暗色玉石、青黑、深褐黑基调。
- 有轻微纹理、暗纹、渐变或边缘压暗。

### 顶部信息栏

- 角色名、境界、生命、灵力、灵石、天数或层数完整可读。
- 信息块像玉牌或暗金边框标签。
- 顶部栏不贴边，字号统一。

### 左侧角色与状态区

- 有角色头像占位框。
- 有境界、资质、心境、气血、灵力等属性。
- 有 3 到 5 个 Buff / 状态小图标。
- 面板有暗金描边，内容分区清楚。

### 中央路线区

- 至少包含战斗、秘境、宝箱、休息、市场 5 个节点。
- 节点之间有路线连线或路径感。
- 已完成、当前、未到达状态区别明显。
- 当前节点有高亮。
- 节点不是纯圆圈加字。

### 右侧卡牌 / 奖励预览区

- 至少 3 张卡牌占位：青木剑诀、聚气术、护身符。
- 每张卡牌都有标题、费用、品质或类型、描述区、边框、图标占位区。
- 卡牌不是白色方块，且整体像游戏卡牌。

### 底部操作区

- 主按钮“继续前进”更大、更亮、更突出。
- 背包、功法、设置、返回按钮风格统一。
- 不出现 Unity 默认灰按钮。

### 秘境事件弹窗样板

- Prefab 内包含默认隐藏的 `EventPopup_StyleSample`。
- 结构包含标题、事件名、描述、两个选项按钮和奖励预览区域。
- 即使默认 inactive，也必须在 Prefab 层级中结构清楚。
