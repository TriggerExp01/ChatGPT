# UI 参考图需求

## 目的

当前 Dev 分支按 `Cultivation / 修仙养成原型` 收束 UI 黄金样板，但这不是最终产品美术方向锁死。参考图用于约束后续 UI 生产，不让 Prefab 继续靠临时审美自由发挥。

没有参考图或正式素材包时，Codex 只能做高质量结构原型和临时视觉资产，不能宣称最终美术完成。

## 当前最需要的参考图类型

### 修仙养成主界面参考图

用于确认：

- 主界面信息密度；
- 角色状态面板组织方式；
- 资源栏表现；
- 修仙题材的色彩和材质；
- 主操作按钮的视觉权重。

### 卡牌展示参考图

用于确认：

- 卡牌比例；
- 费用区、标题区、插画区、描述区结构；
- 稀有度边框；
- 卡牌文字密度；
- 卡组或奖励预览区域的组织方式。

### 路线节点 / 地图路线参考图

用于确认：

- 路线连线风格；
- 已完成、当前、未到达状态；
- 节点图标语言；
- 路线区域的纵深和探索感；
- 节点是否需要地图背景、雾化或路径装饰。

### 秘境事件弹窗参考图

用于确认：

- 半透明遮罩强度；
- 弹窗面板材质；
- 标题、正文、选项、奖励预览的层级；
- 事件选项按钮的形态；
- 文本量较大时的排版规则。

### 奖励结算参考图

用于确认：

- 奖励图标框；
- 多奖励排列方式；
- 稀有奖励强调；
- 获得动画或高亮方向；
- 与卡牌、路线、事件弹窗的风格一致性。

## 参考图最低要求

每类参考图最好至少提供 2-3 张，允许来自：

- 已购买或自有素材包截图；
- 竞品公开截图；
- 概念稿；
- AI 生成方向图；
- 手绘草图或拼贴板。

参考图必须标注用途：是色彩参考、布局参考、材质参考、还是交互状态参考。不要把某张图默认当作所有方面的唯一答案。

## 需要避免的参考方向

- 现代后台管理系统 UI。
- 科幻蓝白 UI。
- 纯文字菜单 UI。
- 旧肉鸽 UI、旧 Battle UI、`Roguelike_StarUI_*` 资源方向。
- 没有边框、没有层次、没有主题材质的极简灰盒。
