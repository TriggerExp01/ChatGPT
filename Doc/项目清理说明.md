# 项目清理说明

## 清理目标

将旧 `TEngine_Game` 项目清理为可开始其他游戏的 Unity + TEngine 空工程骨架。

## 已保留

- TEngine 框架代码与设置。
- Launcher 与热更启动链路。
- `GameEntry`、`Procedure`、`GameApp`、`GameModule`。
- 基础 UI 模块。
- GameProto 与通用 `item` 配置示例。
- Unity 包依赖与工程设置。
- 主场景。
- TEngine 文档与 Unity MCP 说明。

## 已删除

- 旧肉鸽玩法代码。
- 旧 Battle 系列 UI 代码。
- 旧玩法测试。
- 旧 UI Prefab 和美术资源。
- 旧音效、特效、Actor 资源。
- 旧肉鸽配置表和生成代码。
- 演示截图、Steam 展示图、UI 参考图。
- 旧阶段路线、开发日志、视觉资产清单和肉鸽系统文档。

## 当前入口状态

`GameApp.StartGameLogic()` 当前只输出空工程日志，不启动任何旧游戏逻辑。

新游戏入口应从这里开始接入。
