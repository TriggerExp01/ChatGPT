# Phase68 交付说明：接入剩余门派专属法宝

## 结果摘要

本阶段补齐设计文档《完整法宝汇总表》中除魔道外剩余 5 个门派的 10 件专属法宝，并接入对应门派的精英/宝箱法宝池。实现范围只覆盖战斗与 Run 逻辑层，不改 UI 外观、Prefab、场景资源或旧 Godot/旧 Unity 项目内容。

## 实际改动清单

- 剑宗：
  - `剑心玉`：每回合首次攻击附带 1 层剑气印记。
  - `万剑归宗剑`：每打出 3 张攻击功法，第 3 张走统一卡牌伤害管线并获得 +50% 伤害。
- 火云宗：
  - `火云令`：每回合开始对全部存活敌人施加 1 层灼烧，持续 2 回合。
  - `焚天炉`：灼烧回合伤害 +50%。
- 药王谷：
  - `药王鼎`：每场战斗首次使用战斗丹药时，效果翻倍且不消耗丹药。
  - `万毒珠`：本场战斗中毒层数上限 +50。
- 天雷阁：
  - `雷灵珠`：每场战斗首次 1-99% 概率判定失败时，改为成功。
  - `引雷针`：连锁伤害不再衰减，后续链伤害使用主伤害值。
- 玄黄宗：
  - `玄黄鼎`：战斗开始时获得 5 点护盾，作为当前岩甲的逻辑占位实现。
  - `不动明王印`：反击无视敌人防御；每回合首次受到敌人攻击伤害 -50%。
- 魔道：
  - 保留 Phase67 已接入的 `血魔珠`、`天魔心`，并与新门派池共用同一套 `CreateArtifactRewardPool()` 分发。

  - 覆盖 `CultivationBattleEngineTests` 与 `CultivationRunEngineTests`，包含既有丹药、精英掉落、市场、战斗结算与 Run 流程断言。

## 假设与风险

- `玄黄鼎` 的“5 层岩甲”当前按现有战斗模型映射为 5 点护盾；如果后续需要“岩甲层数”和护盾分离，需要新增独立状态。
- `万毒珠` 的“中毒伤害无视免疫”当前没有敌方中毒免疫系统可接入，本阶段先落实中毒上限 +50。
- `焚天炉` 的“引爆灼烧额外 +50%”当前没有灼烧引爆卡牌管线，本阶段先落实持续灼烧伤害 +50%。
- `雷灵珠` 不会把 0% 判定改成成功；只对 1-99% 的真实概率失败生效，避免把“不可触发/禁用效果”误判为保底对象。
