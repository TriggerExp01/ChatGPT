# Phase66 交付说明 - 魔道战斗牌池补齐

## 结果摘要

本阶段在 Phase65 的魔道血祭循环基础上，继续按 `Doc/设计文档/卡牌池设计_魔道.md` 补齐魔道战斗牌池。当前魔道奖励池已经包含设计文档中的 25 张门派战斗牌，并保留 1 张通用 `回春丹` 作为原型期续航补位。

本阶段重点是让魔道从“最小可玩循环”扩展到“完整战斗牌奖励池可抽取、可展示、可由固定种子自动走局评分”的状态。设计文档中的 2 件魔道专属法宝 `血魔珠`、`天魔心` 尚未接入法宝掉落和被动系统，后续应单独作为法宝阶段实现。

## 实际改动清单

- 魔道战斗牌池
  - 新增 15 张魔道战斗牌：`献祭术`、`噬魂术`、`万魔噬心`、`癫狂之血`、`天魔降临`、`万魔朝宗`、`血祭回复`、`魔甲`、`不死魔身`、`血魔不灭`、`血影步`、`天魔遁`、`血祭强化`、`魔血沸腾`、`天魔真解`。
  - `CreateDemonicSectRewardPool()` 扩展为 25 张魔道门派战斗牌 + 1 张通用 `回春丹`。
  - `天魔解体` 增加本回合灵力 +3，保留蓄力翻倍和抽牌，进一步贴近设计文档中的爆发定位。
- 新增战斗效果类型
  - `SacrificeHandCardDamage` / `SacrificeHandCardHeal`：献祭手牌换伤害或回复。
  - `SpiritGain`：本回合获得灵力。
  - `FlatDamageBonus`：本回合出牌伤害加值。
  - `FrenzyDamageBonus`：按损失 HP 档位提高出牌伤害。
  - `BloodlossRetaliation`：玩家失去 HP 时对随机敌人造成反噬伤害。
  - `LowHpDodge`、`SelfDamageDodgeDraw`：低血/自伤触发闪避与过牌收益。
  - `DeathWard`、`DamageTakenHeal`：免死和受伤回血引擎。
- 战斗结算
  - 抽象 `DealCardDamageValue()`，让普通攻击、低血伤害、暴击/连锁伤害、剑气印记追击、噬血伤害统一吃蓄力、平伤加成和癫狂增伤。
  - 统一 `ApplySelfHpLoss()`，记录本回合自伤并触发 `魔血沸腾`。
  - 敌人攻击命中后接入免死和受伤回血。
- UI 与自动走局
  - 原型运行 Presenter 与战斗 UI 增加新增效果的中文描述。
  - `CultivationRunAutoPlayer` 增加新增效果评分，避免完整牌池扩展后自动走局把关键魔道牌视为 0 分。

## 假设与风险

- 本阶段的 `天魔降临` 使用固定 `失去 25 HP / 全体 50 伤害` 表达设计文档的“失去当前 HP 50% 并造成失去量 ×2 全体伤害”原型效果，尚未做动态百分比扣血效果类型。
- `天魔真解` 暂用“自伤反击 + 癫狂增伤”的战斗内原型表达，尚未实现正式三选一 UI、Run 级永久被动或自伤减半。
- `献祭术` 和 `血祭回复` 当前自动选择手牌中灵力最高的 1 张牌作为献祭对象，并移入本场战斗消耗区；还没有玩家手动选择 UI。
- 设计文档中的 2 件魔道专属法宝尚未实装，不计入本阶段完成范围。
