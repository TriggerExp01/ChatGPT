# 2D 肉鸽最小可玩版说明

## 当前已实现

- 固定测试地图和边界。
- WASD 二维移动。
- 敌人从地图边缘生成、追踪玩家并造成接触伤害。
- 指定方向范围攻击。
- 经验与金币掉落、吸附和拾取。
- 等级、升级随机三选一和五类属性强化。
- 随时间提升刷怪数量与敌人强度。
- 生命、经验、等级、时间、击杀、升级和结算 UI。
- 死亡结算、重新开始和永久金币。

## 与目标玩法的已知偏差

- 目标是武器自动寻找附近敌人；当前仍由鼠标或方向键指定攻击方向。
- 玩家与敌人移动尚未使用 `Rigidbody2D`。
- 当前使用运行时生成的简单显示对象，尚未切换为正式 Prefab 和美术资源。
- 当前生存数值主要硬编码，尚未迁移到 Luban。

## 当前操作

- `WASD`：移动
- 鼠标或方向键：控制当前攻击方向
- `Esc`：暂停或继续
- `R`：重新开始
