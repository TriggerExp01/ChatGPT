# 2D 肉鸽最小可玩版说明

## 当前已实现

- 固定测试地图和边界，玩家位置已通过边界夹取验收。
- WASD 二维移动。
- 敌人从地图边缘生成、追踪玩家并造成接触伤害。
- 武器自动寻找附近敌人并发射投射物，当前包含追踪魔弹、旋刃和穿透飞镖。
- 经验与金币掉落、吸附和拾取，其中经验掉落吸附和收集已通过 Play Mode 验收。
- 等级、升级随机三选一和五类属性强化。
- 随时间通过配置化刷怪阶段提升刷怪数量与敌人强度。
- 多武器、武器升级和少量被动道具构筑。
- 敌人、掉落物、投射物运行时对象接入 TEngine `MemoryPool`，战斗临时视图已复用。
- 敌人基础数值、升级奖励、被动效果、武器基础数值和刷怪阶段已接入 Luban 配置表。
- 生命、经验、等级、时间、击杀、升级和结算 UI。
- 受击闪白、拾取脉冲、短时相机震动和最小音效反馈。
- 死亡结算、重新开始和永久金币。

## 与目标玩法的已知偏差

- 当前使用运行时生成的简单显示对象，尚未切换为正式 Prefab 和美术资源。
- 当前音效为最小 WAV 占位资源，后续仍需替换为正式音频资产。
- 部分战斗编排逻辑仍集中在 `RoguelikeGame`，后续扩展时再按实际复杂度做最小拆分。

## 当前操作

- `WASD`：移动
- `Esc`：暂停或继续
- `R`：重新开始

## 当前验收边界

当前原型已通过阶段 16-20 Play Mode 验收，第一轮内容扩展已完成。正式阶段状态以 [类吸血鬼幸存者阶段开发路线.md](D:/Work/Unity_Project/TEngine_Game/Doc/类吸血鬼幸存者阶段开发路线.md:1) 为准。

- 在仓库根目录运行 `dotnet build UnityProject\UnityProject.sln --no-restore`
- 在仓库根目录运行 `git diff --check`
- Unity Play Mode 验证移动、刷怪、追踪、受伤、攻击、掉落、升级、结算和重开
