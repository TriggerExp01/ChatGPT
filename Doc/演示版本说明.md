# 演示版本说明

## 版本定位

当前版本是类《吸血鬼幸存者》的 2D 自动战斗肉鸽可演示版本，目标是用于内部审查、Steam 商店页视觉方向讨论和下一轮开发立项。版本重点不是内容量，而是证明核心闭环已经能从开局、移动、自动战斗、掉落、升级、构筑、Boss 胜利、结算和重开顺畅跑通。

## 当前可演示能力

- 玩家使用 `WASD` 在固定场地内移动，场地包含边界和轻量障碍。
- 武器会自动寻找敌人并攻击，当前包含追踪魔弹、旋刃、穿透飞镖和星环脉冲。
- 敌人会按配置化刷怪阶段持续出现，包含普通敌人、精英敌人和 600 秒目标 Boss。
- 击败敌人会掉落经验和金币，掉落物已使用正式 Sprite 表现，并具备吸附与拾取反馈。
- 命中会显示世界空间伤害数字，普通、重击和暴击使用不同颜色、字号、阴影和上浮节奏。
- 升级时进入三选一卡牌界面，可选择武器、被动、属性或金币消耗型补给。
- HUD 已具备角色状态、时间压力、构筑槽和低遮挡战斗提示；构筑槽已能按具体武器和被动类型显示 Kenney CC0 图标。
- 结算面板展示胜负、战斗数据、本局收益、永久金币成长和重开入口。
- 展示截图模式已能隐藏底部操作提示和 HUD 提示条，并降低上方 HUD 遮挡，用于自然战斗和结算截图准备。
- 对象池、高密度对象压测、性能快照和配置校验已经具备 Play Mode 覆盖。

## 推荐演示路径

1. 开局演示：进入 Play Mode 后展示 HUD，说明 `WASD` 移动、自动攻击最近敌人、经验晶体升级和底部低遮挡提示。
2. 战斗演示：使用阶段 46 展示构图入口或运行时状态展示自然敌群、投射物、正式化掉落物、伤害飘字、带正式图标的构筑槽和对象池稳定性；展示入口会自动开启阶段 47 的低遮挡截图 UI。
3. 升级演示：触发升级三选一，展示二次元轻幻想卡牌、正式化第一轮图标、金币消耗和不可选状态。
4. 结算演示：触发胜利或失败结算，展示永久金币成长、下局初始攻击加成和重开闭环。

## Steam 展示图方向验证

- 升级奖励三选一图可作为奖励卡牌和图标化构筑方向参考；阶段 43/48 已补齐第一轮免费正式图标，但当前仍需要正式角色立绘和卡面资产。
- 高密度战斗图确认敌人与投射物没有继续出现异常放大，尺寸修复有效；但当前构图偏规则矩阵，更适合作为技术验收图，不建议直接作为最终 Steam 商店图。
- 阶段 46 已新增固定种子的自然战斗展示构图入口，阶段 47 已补充低遮挡截图 UI 控制，阶段 48 已补齐 HUD 构筑槽的具体武器/被动图标，阶段 49 已增强普通/重击/暴击伤害飘字可读性，阶段 50 已让经验/金币掉落物使用正式 Sprite；后续 Steam 战斗截图应优先基于该入口再做固定镜头和分辨率输出。
- 结算成长图能展示胜利、收益和局外成长闭环；阶段 47 已支持隐藏结算提示，正式截图前仍建议进一步压暗或整理结算背景。
- 详细记录见 `Doc/Steam展示图验证记录.md`。

## 验收结论

- `dotnet build UnityProject\UnityProject.sln --no-restore` 应保持 0 Error。
- `git diff --check` 应保持通过。
- Unity MCP 必须能读取 `editor/state`，并能执行 `read_console`、`run_tests` 和截图。
- 全量 Play Mode `GameLogic.PlayModeTests` 应以当前阶段测试输出为准并保持全部通过。
- Unity 控制台最终应为 0 Error。

## 已知不足

- 当前视觉仍以运行时生成 Sprite、轻量 Prefab、伤害飘字和第一轮免费图标为主，正式角色立绘、卡面和 Steam 展示图仍待免费可商用资源与 GPT 绘画补齐。
- 当前音效为最小 WAV 占位资源，后续需要替换为正式混音资产。
- 部分战斗编排逻辑仍集中在 `RoguelikeGame`，下一轮扩展时可按实际复杂度做最小拆分。
- 当前仍未形成固定分辨率截图批处理和最终 Steam 候选图输出。

## 下一轮建议边界

- 优先进入正式美术资产下一轮：角色头像、奖励卡底图、截图构图补强，以及必要时继续细化武器/被动图标与高价值掉落表现。
- 保持免费可商用资源加 GPT 绘画策略，并记录每个外部资源的来源、作者、许可和用途。
- 不在下一轮一开始引入复杂技能树、稀有度、武器进化或第二套 UI 框架。
- 下一步应从“方向验证图”进入“自然商店图制作”：基于阶段 46 展示构图和阶段 47 低遮挡 UI 状态，补正式视觉资产、固定分辨率截图输出，再生成可用于 Steam 页面讨论的成稿候选。
