# 验收清单

## 通用代码验证

```bash
dotnet build UnityProject.sln --no-restore
git diff --check
```

必须检查：

- 编译 0 Error。
- 没有尾随空格或非法 diff。
- 没有无关文件被修改。
- 没有误删 `.meta`。

## Unity MCP 验证

在 Codex 可使用 Unity MCP 时，优先读取：

```text
mcpforunity://editor/state
```

确认：

- Unity Editor 打开的是当前项目。
- `ready_for_tools = true`。
- `is_compiling = false`。
- `is_domain_reload_pending = false`。
- 当前场景符合任务要求。

然后按需调用：

```text
find_gameobjects
read_console
```

## Play Mode 验收

每个阶段必须有可视化验收点。

### 移动/敌人/伤害

- 玩家可移动。
- 玩家不能越界。
- 暂停时不移动。
- 敌人从四周生成。
- 敌人追踪玩家。
- 接触伤害生效。
- 死亡进入结算。

### 武器

- 武器能自动寻找目标。
- 投射物或攻击表现可见。
- 命中后敌人扣血。
- 敌人死亡后击杀数增加。
- 多武器阶段要验证多个武器同时执行。

### 升级

- 经验可拾取。
- 升级时进入三选一。
- 三选一时局内时间冻结。
- 选择后恢复运行。
- 强化效果立即生效。

### UI

- HUD 正确显示生命、经验、等级、时间、击杀。
- 升级界面可点击。
- 结算界面可重开。
- 按钮文字不裁切。

### 性能基础检查

- 敌人数量增加时没有明显编辑器卡死。
- 投射物不会无限残留。
- 掉落物不会无限残留。
- 控制台无持续刷屏日志。

## 阶段 7 验收清单：多武器与武器升级

- 玩家可同时拥有至少两种武器。
- 两种武器表现差异明确。
- 两种武器都能造成伤害。
- 升级三选一可以出现“获得新武器”。
- 已拥有武器后可以出现“升级已有武器”。
- 选择升级后效果立即生效。
- 不提前实现复杂技能树、词条、稀有度、武器进化。
- Unity Console 0 Error。

## 阶段 8 验收清单：被动道具与构筑

- 被动道具可以通过三选一获得。
- 被动效果与武器或玩家属性产生构筑关系。
- 被动效果可在 UI 或日志中确认。
- 不提前做复杂装备栏和背包系统。

## 阶段 9 验收清单：对象池与性能优化

- 优先确认 TEngine 是否已有对象池方案。
- 投射物、敌人、掉落物优先接入对象池。
- 对象回收后状态正确重置。
- 无明显 GC 或残留对象问题。

## 阶段 13 验收清单：Luban 配置化

- 敌人、武器、升级选项、刷怪规则按顺序迁移。
- 配置生成脚本可运行。
- 运行时代码读取配置成功。
- 硬编码数值减少。
- 配置错误有可定位日志。
