# Codex 任务模板

你可以把下面内容复制给 Codex 使用。

```text
按 AGENTS.md 和 .codex-studio 规则执行本任务。

任务：
【在这里写具体任务】

要求：
1. 先读取 Doc/文档索引.md、阶段路线、系统总览、框架指南、开发日志。
2. 确认当前阶段，只推进当前阶段范围内的内容。
3. 优先复用 TEngine、GameModule、UIModule、YooAsset、Luban、HybridCLR 相关既有能力。
4. 不主动引入 Addressables。
5. 不修改 Assets/TEngine，除非任务明确需要。
6. 不删除 .meta。
7. 完成后执行 dotnet build UnityProject.sln --no-restore 和 git diff --check。
8. 如 Unity MCP 可用，读取 editor/state 和控制台，并进行 Play Mode 验收。
9. 更新 Doc/开发日志.md。
10. 最终回复包含：完成内容、改动文件、实现原因、验证结果、风险点、下一步建议。
```

## 阶段 7 专用任务模板

```text
按 AGENTS.md 和 .codex-studio 规则，推进阶段 7：多武器与武器升级。

范围：
1. 在现有自动投射物武器基础上增加第二种差异化武器。
2. 让升级三选一可以获得新武器或提升已有武器。
3. 保持武器执行简单，不提前建设复杂技能树、词条、稀有度、武器进化。
4. Play Mode 验证多武器同时执行和升级结果。

建议第二武器：旋转环绕球，要求可见、可伤害敌人、可升级。

完成后：
- 编译验证。
- git diff 检查。
- Unity Console 检查。
- 更新开发日志。
```

## 阶段 8 专用任务模板

```text
按 AGENTS.md 和 .codex-studio 规则，推进阶段 8：被动道具与构筑。

范围：
1. 在三选一中加入被动道具。
2. 被动道具影响玩家属性或武器效果。

```
